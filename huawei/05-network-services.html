Network Services

04.1 DHCP Server (Interface-based)

[HUAWEI] dhcp enable
[HUAWEI] interface vlanif 20
[HUAWEI-Vlanif20] ip address 192.168.20.1 255.255.255.0
[HUAWEI-Vlanif20] dhcp select interface
[HUAWEI-Vlanif20] dhcp server dns-list 10.10.10.10 8.8.8.8
[HUAWEI-Vlanif20] dhcp server gateway-list 192.168.20.1
[HUAWEI-Vlanif20] dhcp server lease day 3 hour 0
[HUAWEI-Vlanif20] dhcp server excluded-ip-address 192.168.20.2 192.168.20.10
[HUAWEI-Vlanif20] quit

04.2 DHCP Relay

[HUAWEI] interface vlanif 30
[HUAWEI-Vlanif30] ip address 192.168.30.1 255.255.255.0
[HUAWEI-Vlanif30] dhcp select relay
[HUAWEI-Vlanif30] dhcp relay server-ip 10.10.10.50
[HUAWEI-Vlanif30] dhcp relay server-detect
[HUAWEI-Vlanif30] quit

04.3 DHCP Snooping + DAI + IPSG

[HUAWEI] dhcp snooping enable
[HUAWEI] vlan 20
[HUAWEI-vlan20] dhcp snooping enable
[HUAWEI-vlan20] dhcp snooping check arp enable      # DAI
[HUAWEI-vlan20] quit

[HUAWEI] interface gigabitethernet 0/0/25
[HUAWEI-GigabitEthernet0/0/25] dhcp snooping trusted
[HUAWEI-GigabitEthernet0/0/25] quit

[HUAWEI] port-group access_ports
[HUAWEI-port-group-access_ports] dhcp snooping limit rate 10
[HUAWEI-port-group-access_ports] ip source check user-bind enable   # IPSG
[HUAWEI-port-group-access_ports] quit

04.4 DNS Client

[HUAWEI] dns resolve
[HUAWEI] dns server 10.10.10.10
[HUAWEI] dns server 8.8.8.8

04.5 ARP & ND

[HUAWEI] arp aging-time 1200
[HUAWEI] arp anti-attack gateway-duplicate enable
[HUAWEI] arp anti-attack user-valid enable

04.6 VRRP (Gateway HA)

[HUAWEI] interface vlanif 20
[HUAWEI-Vlanif20] vrrp vrid 1 virtual-ip 192.168.20.254
[HUAWEI-Vlanif20] vrrp vrid 1 priority 120
[HUAWEI-Vlanif20] vrrp vrid 1 preempt-mode timer delay 30
[HUAWEI-Vlanif20] vrrp vrid 1 track interface gigabitethernet 0/0/25 reduced 30
[HUAWEI-Vlanif20] vrrp vrid 1 version 3
[HUAWEI-Vlanif20] quit

04.7 IP Performance / UDP Helper

[HUAWEI] ip forwarding
[HUAWEI] ip ttl-expires enable
[HUAWEI] interface vlanif 20
[HUAWEI-Vlanif20] ip helper-address 10.10.10.50    # DHCP relay alternative
