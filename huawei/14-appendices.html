99.2 Password Recovery (BootROM)

# 1. Console connect (9600-8-N-1)
# 2. Power cycle switch
# 3. When "Press Ctrl+B to enter boot menu..." appears → Press Ctrl+B
# 4. Enter BootROM password (default: Admin@huawei.com atau huawei)
# 5. Menu: "Clear password for console user"
# 6. Menu: "Boot with default mode"
# 7. After boot (no password):
<HUAWEI> system-view
[HUAWEI] aaa
[HUAWEI-aaa] local-user admin password irreversible-cipher NewP@ss123!
[HUAWEI-aaa] quit
[HUAWEI] save

99.4 USB Zero-Touch Deployment

USB (FAT32) contents:
├── auto_run.cfg          # Python script atau CLI batch
├── system-software.cc    # Firmware image
├── startup.cfg           # Startup config
└── custom.py             # Optional custom script

auto_run.cfg example:
system-view
sysname SW-${MAC}
vlan batch 10 20 30
interface Vlanif10
ip address 10.10.10.${LAST_OCTET} 24
stp mode mstp
save
reboot
