Hardware & Diagnostics

02.1 Device Health

<HUAWEI> display device                     # Slot/card status
<HUAWEI> display environment                # Temp, fan, power, voltage
<HUAWEI> display power                      # Power supply detail
<HUAWEI> display fan                        # Fan speed, status
<HUAWEI> display temperature                # All sensors
<HUAWEI> display cpu-usage                  # CPU 5s/1m/5m
<HUAWEI> display memory-usage               # Memory utilization
<HUAWEI> display health                     # Overall health score

02.2 Optics / Transceiver

<HUAWEI> display transceiver interface gigabitethernet 0/0/25
<HUAWEI> display transceiver diagnosis interface gigabitethernet 0/0/25   # DDM: Rx/Tx power, temp, voltage
<HUAWEI> display transceiver manuinfo interface gigabitethernet 0/0/25   # Vendor, PN, SN

02.3 Interface Physical Status

<HUAWEI> display interface brief            # All ports: up/down, speed, duplex
<HUAWEI> display interface gigabitethernet 0/0/1    # Counters, errors, CRC
<HUAWEI> display counters error interface gigabitethernet 0/0/1
<HUAWEI> display counters rate interface gigabitethernet 0/0/1

02.4 PoE Status (Access Switch)

<HUAWEI> display poe interface all
<HUAWEI> display poe power-state
<HUAWEI> display poe power-budget
