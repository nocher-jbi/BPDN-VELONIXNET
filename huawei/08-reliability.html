07.5 Smart Link / Monitor Link

# Smart Link (Fast failover < 50ms)
[HUAWEI] smart-link group 1
[HUAWEI-smlk-group1] port gigabitethernet 0/0/25 master
[HUAWEI-smlk-group1] port gigabitethernet 0/0/26 slave
[HUAWEI-smlk-group1] flush send control-vlan 100
[HUAWEI-smlk-group1] restore enable
[HUAWEI-smlk-group1] restore time 30
[HUAWEI-smlk-group1] quit
[HUAWEI] smart-link enable

# Monitor Link (Uplink → Downlink)
[HUAWEI] monitor-link group 1
[HUAWEI-mlk-group1] port gigabitethernet 0/0/25 uplink
[HUAWEI-mlk-group1] port gigabitethernet 0/0/1 downlink
[HUAWEI-mlk-group1] quit
[HUAWEI] monitor-link enable
