Panduan Huawei Switch (Bahasa Indonesia)

Panduan Huawei Switch

Buku panduan konfigurasi switch Huawei untuk tim NOC — disusun mengikuti struktur manual MikroTik: Getting Started, topik per bidang, Developer Guides, lalu CLI Reference. Mencakup seri campus (S220/S310/S530/S620, S5700/S6700) dan data center (CloudEngine).

Catatan Template konfigurasi bersifat baseline — sesuaikan dengan topologi, kebijakan keamanan, dan SLA organisasi. Validasi di lab sebelum produksi.

Daftar Bab

  • Getting Started — Login, version check, management IP, AAA, save & backup
  • Management Plane — AAA/RADIUS, SNMP, NTP/PTP, Web, NETCONF/RESTCONF/gNMI, OPS, upgrade firmware
  • Hardware & Diagnostics — Device health, optics/DDM, interface counters, PoE
  • Wired Switching — VLAN, port modes, Eth-Trunk/LACP/M-LAG, MAC, STP/MSTP/ERPS, QinQ
  • Network Services — DHCP server/relay/snooping, DNS, ARP, VRRP, IP performance
  • Routing — Static, OSPF, IS-IS, BGP, route policy, VRF
  • MPLS & VPN — MPLS LDP, L3VPN, EVPN/VXLAN, Segment Routing
  • Reliability — BFD, NSR/GR, DLDP, Smart Link/Monitor Link, M-LAG, CSS/iStack
  • QoS — Classifier/behavior/policy, CPCAR, PFC/ECN
  • Security — NAC (802.1X/MAC/Portal), ACL, port security, storm control, ARP anti-spoof, SSH hardening
  • WLAN AC — AP group, SSID profile, security profile, VAP profile
  • Developer Guides — NETCONF/YANG, RESTCONF, gNMI telemetry, OPS Python, iMaster NCE API
  • CLI Reference — Command lookup by console path + display verification commands
  • Appendices — Cisco CLI cheat sheet, password recovery, factory reset, USB ZTP, EDOC IDs, references
