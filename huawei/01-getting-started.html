Panduan Huawei Switch (Bahasa Indonesia)

Getting Started

00.1 First Login & Console Access

# Console: 9600 8N1, no flow control
# Default user: admin / (no password) atau Admin@huawei.com

<HUAWEI> system-view
[HUAWEI] sysname SW-ACCESS-01
[HUAWEI] clock timezone WIB add 07:00:00
[HUAWEI] clock datetime 14:30:00 2026-11-26

00.2 Version & Hardware Check

<HUAWEI> display version                    # Software version, boot image
<HUAWEI> display device                     # Chassis, slot, card status
<HUAWEI> display device manuinfo            # Serial, MAC, manufacture date
<HUAWEI> display elabel                     # Electronic label (part number)
<HUAWEI> display patch-information          # Installed patches

00.3 Management Interface (Out-of-Band)

[HUAWEI] interface Meth0/0/0                # atau MEth0/0/0
[HUAWEI-MEth0/0/0] ip address 10.10.10.2 255.255.255.0
[HUAWEI-MEth0/0/0] quit
[HUAWEI] ip route-static 0.0.0.0 0.0.0.0 10.10.10.1

00.4 Basic AAA & Remote Access

[HUAWEI] aaa
[HUAWEI-aaa] local-user admin password irreversible-cipher P@ssw0rd123!
[HUAWEI-aaa] local-user admin privilege level 15
[HUAWEI-aaa] local-user admin service-type terminal ssh web

[HUAWEI] user-interface vty 0 4
