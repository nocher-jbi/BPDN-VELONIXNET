Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

BAB I — Arsitektur Sistem & Persiapan

1.1 Tujuan dan Ruang Lingkup

Dokumen ini berfungsi sebagai acuan standar bagi tim IT dalam melakukan instalasi, konfigurasi, operasional harian, pencadangan data (backup), dan pemulihan bencana (disaster recovery) pada infrastruktur virtualisasi kantor yang terdiri atas 3 (tiga) unit server fisik: dua server komputasi Proxmox Virtual Environment (PVE) dan satu server pencadangan khusus Proxmox Backup Server (PBS).

1.2 Topologi dan Alokasi Server

Gunakan skema penamaan (hostname) dan pengalamatan IP statis yang seragam sebelum memulai instalasi. Nilai IP di bawah ini merupakan contoh standar yang dapat disesuaikan dengan segmen VLAN/subnet server kantor:

pve-node1.dputr.local

  • Peran Server: Compute Node 1
  • Contoh Alamat IP: 192.168.10.11/24
  • Fungsi Utama: Menjalankan VM/CT produksi utama

pve-node2.dputr.local

  • Peran Server: Compute Node 2
  • Contoh Alamat IP: 192.168.10.12/24
  • Fungsi Utama: Menjalankan VM/CT produksi & target migrasi

pbs-server.dputr.local

  • Peran Server: Backup & QDevice
  • Contoh Alamat IP: 192.168.10.13/24
  • Fungsi Utama: Penyimpanan backup terdeduplikasi & pemberi suara ke-3 (Quorum)

1.3 Catatan Arsitektur: Quorum pada Cluster 2-Node

Secara bawaan, Proxmox Cluster menggunakan protokol Corosync yang membutuhkan suara mayoritas (quorum) lebih dari 50% untuk mengizinkan perubahan konfigurasi dan menjalankan High Availability. Pada cluster yang hanya memiliki 2 node, matinya 1 node mengakibatkan suara tersisa 1 dari 2 (50%), sehingga cluster terkunci (read-only) untuk mencegah kondisi split-brain.

Untuk mengatasi hal tersebut pada infrastruktur 3 server ini, Server PBS (pbs-server) wajib difungsikan sekaligus sebagai Corosync QDevice (pemberi suara ke-3 tanpa menjalankan VM). Dengan demikian, jika salah satu node PVE mengalami gangguan, node PVE yang tersisa tetap memiliki 2 dari 3 suara (66,7%) dan operasional tetap berjalan normal.

1.4 Persiapan Perangkat Keras dan BIOS/UEFI

Sebelum instalasi dilakukan pada ketiga server, pastikan persyaratan berikut telah terpenuhi:

  • Virtualisasi CPU: Aktifkan fitur Intel VT-x / VT-d atau AMD-V / AMD-Vi pada BIOS/UEFI (wajib untuk pve-node1 dan pve-node2).
  • Konfigurasi Penyimpanan:
  • Jika menggunakan ZFS (direkomendasikan untuk fitur replikasi antar node), atur RAID Controller ke mode HBA / IT Mode (nonaktifkan Hardware RAID).
  • Jika menggunakan Hardware RAID, buat konfigurasi RAID 1 untuk OS dan RAID 10/5/6 untuk penyimpanan VM, lalu gunakan filesystem LVM-Thin atau ext4.
  • Jaringan: Disarankan memisahkan trafik manajemen/cluster dan trafik jaringan VM/backup menggunakan port NIC fisik terpisah atau VLAN.
  • Media Instalasi: Siapkan USB bootable berisi berkas ISO resmi terbaru untuk Proxmox VE dan Proxmox Backup Server (gunakan tool seperti BalenaEtcher, Ventoy, atau Rufus dalam mode DD Image).
