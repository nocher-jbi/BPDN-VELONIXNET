Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

BAB II — Instalasi & Konfigurasi Proxmox VE

Lakukan seluruh langkah pada bab ini secara bergantian pada pve-node1 dan pve-node2.

2.1 Prosedur Instalasi Proxmox VE

  1. Booting Media Instalasi: Nyalakan server, masuk ke Boot Menu, dan pilih USB bootable Proxmox VE. Pilih Install Proxmox VE (Graphical).
  2. Persetujuan Lisensi (EULA): Baca ketentuan lisensi lalu klik I agree.
  3. Target Harddisk & Filesystem: Pilih disk tujuan instalasi. Klik Options untuk memilih filesystem: gunakan ZFS (RAID1) jika tersedia 2 disk OS tanpa Hardware RAID, atau ext4 / LVM jika menggunakan Hardware RAID.
  4. Lokasi dan Zona Waktu: Atur Country ke Indonesia, Time zone ke Asia/Jakarta (atau sesuai zona waktu kantor), dan Keyboard Layout ke U.S. English.
  5. Kredensial Administrator: Masukkan kata sandi root yang kuat (kombinasi huruf besar, kecil, angka, dan simbol) serta alamat email resmi tim IT untuk notifikasi sistem.
  6. Konfigurasi Jaringan: Pilih antarmuka manajemen (Management Interface). Masukkan Hostname (FQDN) (contoh: pve-node1.dputr.local), IP Address (CIDR), Gateway, dan DNS Server internal.
  7. Konfirmasi dan Instalasi: Periksa ringkasan konfigurasi, pastikan opsi Automatically reboot after successful installation dicentang, lalu klik Install. Cabut USB instalasi saat server melakukan reboot.

2.2 Akses Antarmuka Web (Web GUI)

Setelah server menyala kembali, akses antarmuka manajemen melalui peramban web pada komputer admin:

  • URL:https://<IP-Node>:8006 (contoh: https://192.168.10.11:8006)
  • Username:root | Realm:Linux PAM standard authentication

2.3 Konfigurasi Pasca-Instalasi (Wajib)

Lakukan langkah berikut pada kedua node segera setelah instalasi selesai:

  1. Pengaturan Repositori: Jika kantor tidak menggunakan lisensi berbayar (Enterprise), buka menu Node > Updates > Repositories. Pilih repositori pve-enterprise dan ceph (enterprise), lalu klik Disable. Klik Add, lalu tambahkan repositori No-Subscription.
  2. Pembaruan Sistem: Buka Node > Shell dan jalankan perintah berikut untuk memperbarui paket sistem dan kernel:
apt update && apt full-upgrade -y

Lakukan reboot jika terdapat pembaruan kernel (reboot).
3. Sinkronisasi Waktu (NTP): Pastikan waktu antar server sinkron agar Corosync Cluster dan jadwal backup berjalan akurat. Periksa status melalui shell:

chronyc tracking

Jika server tidak terhubung langsung ke internet, arahkan konfigurasi /etc/chrony/chrony.conf ke NTP Server internal kantor, lalu jalankan systemctl restart chrony.
