Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

Pra-Implementasi: Lembar Parameter

Seluruh alamat IP, hostname, nama storage, dan jadwal di dalam buku panduan ini menggunakan nilai contoh standar; sebelum instalasi dimulai, Tim IT wajib mengisi dan menyepakati parameter aktual lingkungan kantor pada tabel-tabel berikut, lalu menyimpannya kembali sebagai dokumentasi As-Built setelah selesai implementasi.

A. Identitas Instansi dan Penanggung Jawab

Nama Instansi / Kantor

  • Contoh: Dinas Pekerjaan Umum dan Tata Ruang (DPUTR)
  • Nilai aktual: Isi sesuai instansi
  • Keterangan: Digunakan pada kop dan dokumentasi resmi

Unit Kerja / Tim Pengelola

  • Contoh: Bidang / Tim IT
  • Nilai aktual: Isi unit kerja
  • Keterangan: Pemilik operasional infrastruktur server

Penanggung Jawab (PIC)

  • Contoh: Koordinator IT
  • Nilai aktual: Isi nama & kontak
  • Keterangan: Kontak eskalasi saat gangguan kritikal

Email Notifikasi Sistem

  • Contoh: it-ops@kantor.local
  • Nilai aktual: Isi email tim IT
  • Keterangan: Penerima alert backup gagal, SMART disk, dan error sistem

B. Pengalamatan Jaringan, VLAN, dan Hostname

Domain Internal

  • Contoh: dputr.local
  • Nilai aktual: Isi domain internal
  • Keterangan: Suffix FQDN seluruh server

Hostname & IP PVE Node 1

  • Contoh: pve-node1.dputr.local (192.168.10.11/24)
  • Nilai aktual: Isi Hostname & IP
  • Keterangan: Server komputasi utama (IP statis)

Hostname & IP PVE Node 2

  • Contoh: pve-node2.dputr.local (192.168.10.12/24)
  • Nilai aktual: Isi Hostname & IP
  • Keterangan: Server komputasi kedua & target migrasi (IP statis)

Hostname & IP Server PBS

  • Contoh: pbs-server.dputr.local (192.168.10.13/24)
  • Nilai aktual: Isi Hostname & IP
  • Keterangan: Server backup & Corosync QDevice (IP statis)

Default Gateway

  • Contoh: 192.168.10.1
  • Nilai aktual: Isi IP Gateway
  • Keterangan: Router/gateway segmen manajemen server

DNS Server (Primary & Secondary)

  • Contoh: 192.168.10.2 / 8.8.8.8
  • Nilai aktual: Isi IP DNS
  • Keterangan: DNS internal kantor dan/atau DNS publik

VLAN Manajemen & Cluster

  • Contoh: VLAN 10 (Dedicated)
  • Nilai aktual: Isi VLAN ID / NIC
  • Keterangan: Disarankan terpisah dari trafik pengguna

VLAN / Subnet Jaringan VM

  • Contoh: VLAN 20, 30, dst.
  • Nilai aktual: Isi daftar VLAN VM
  • Keterangan: Segmen jaringan aplikasi/layanan produksi

IP / Subnet Whitelist Admin

  • Contoh: 192.168.10.0/24 atau VPN
  • Nilai aktual: Isi IP/Subnet Admin
  • Keterangan: Daftar IP yang diizinkan mengakses port 8006, 8007, dan SSH 22

C. Konfigurasi Cluster, Sistem, dan Waktu

Nama Cluster Proxmox

  • Contoh: cluster-dputr
  • Nilai aktual: Isi nama cluster
  • Keterangan: Tanpa spasi, unik di jaringan kantor

Zona Waktu (Timezone)

  • Contoh: Asia/Jakarta (WIB)
  • Nilai aktual: WIB / WITA / WIT
  • Keterangan: Harus seragam di ketiga server

NTP Server

  • Contoh: Default pool / internal
  • Nilai aktual: Isi IP NTP internal
  • Keterangan: Wajib sinkron agar Corosync Cluster & jadwal backup akurat

Status Lisensi Proxmox

  • Contoh: No-Subscription
  • Nilai aktual: No-Subscription / Enterprise
  • Keterangan: Menentukan repositori paket yang diaktifkan

SMTP Relay / Mail Server

  • Contoh: Opsional
  • Nilai aktual: Isi host & port SMTP
  • Keterangan: Diperlukan agar notifikasi email otomatis terkirim

D. Penyimpanan (Storage) dan Spesifikasi Perangkat Keras

Mode RAID Controller

  • Contoh: HBA / IT Mode (untuk ZFS)
  • Nilai aktual: HBA/IT Mode atau HW RAID
  • Keterangan: Jangan jalankan ZFS di atas Hardware RAID

Filesystem OS & VM (PVE)

  • Contoh: ZFS (RAID1) / LVM-Thin
  • Nilai aktual: Isi pilihan filesystem
  • Keterangan: Wajib ZFS dengan Storage ID sama jika ingin fitur Replikasi antar node

Nama Storage ID VM (PVE)

  • Contoh: local-zfs / local-lvm
  • Nilai aktual: Isi nama Storage ID
  • Keterangan: Harus identik di Node 1 dan Node 2 untuk kemudahan migrasi

Konfigurasi Disk Datastore PBS

  • Contoh: ZFS Mirror / RAIDZ1-Z2
  • Nilai aktual: Isi topologi disk PBS
  • Keterangan: Pisahkan disk OS PBS dari disk Datastore backup

Nama Datastore PBS

  • Contoh: backup-produksi
  • Nilai aktual: Isi nama datastore
  • Keterangan: Target penyimpanan backup di Server PBS

Nama Storage PBS di PVE

  • Contoh: pbs-dputr
  • Nilai aktual: Isi ID storage di PVE
  • Keterangan: Nama tampilan storage backup di Web GUI PVE

Tipe CPU Standar VM

  • Contoh: host / x86-64-v2-AES
  • Nilai aktual: Isi tipe CPU
  • Keterangan: Gunakan x86-64-v2-AES jika generasi CPU Node 1 & Node 2 berbeda

E. Keamanan, Manajemen Akun, dan Kebijakan Backup

Daftar Akun Staf IT & Role

  • Contoh: Admin / Operator individual
  • Nilai aktual: Isi daftar username & role
  • Keterangan: Hindari berbagi akun root untuk kerja harian

User & API Token Backup PBS

  • Contoh: pve-backup@pbs!cluster-token
  • Nilai aktual: Isi nama user & token
  • Keterangan: Simpan Secret API Token di password manager resmi tim IT

Aplikasi 2FA / TOTP

  • Contoh: Google Authenticator / FreeOTP
  • Nilai aktual: Isi standar 2FA tim IT
  • Keterangan: Wajib aktif untuk semua akun administrator PVE & PBS

Jadwal Backup Otomatis

  • Contoh: Setiap hari pukul 01:00
  • Nilai aktual: Isi jam backup
  • Keterangan: Pilih di luar jam operasional kantor agar tidak mengganggu performa

Kebijakan Retensi (Prune)

  • Contoh: Daily: 7, Weekly: 4, Monthly: 6
  • Nilai aktual: Isi kebijakan retensi
  • Keterangan: Sesuaikan dengan kapasitas disk PBS & aturan retensi data kantor

Jadwal Verify & Garbage Collection

  • Contoh: Verify Sabtu 02:00 / GC Minggu 04:00
  • Nilai aktual: Isi jadwal Verify & GC
  • Keterangan: Pastikan tidak bertabrakan dengan jam Backup Job
