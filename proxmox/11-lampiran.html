Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

Lampiran — Checklist Kesiapan Produksi

Sebelum infrastruktur dinyatakan siap beroperasi penuh (Go-Live), tim IT wajib memverifikasi seluruh poin berikut:

  • pve-node1, pve-node2, dan pbs-server terpasang dengan IP Statis dan NTP sinkron.
  • Repositori non-enterprise aktif dan seluruh server sudah diperbarui ke versi stabil terbaru.
  • Cluster PVE 2-node terbentuk dan QDevice pada pbs-server aktif (Total votes: 3 pada pvecm status).
  • Uji coba failover quorum: mematikan 1 node PVE tidak mengunci antarmuka node lainnya.
  • Datastore PBS terhubung ke Cluster PVE menggunakan API Token khusus (bukan root).
  • Backup Job, Prune Job, Verify Job, dan Garbage Collection telah terjadwal otomatis.
  • Uji coba Backup & Restore minimal 1 VM telah berhasil dilakukan.
  • Autentikasi 2FA telah diaktifkan pada akun administrator PVE dan PBS.
  • Seluruh tabel pada bagian Pra-Implementasi (IP aktual, Hostname, VLAN, Storage, dan Kebijakan Backup) telah diisi lengkap dan diarsipkan sebagai dokumen As-Built Tim IT.
