Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

BAB VI — Backup, Verifikasi & Restore

6.1 Penjadwalan Backup Otomatis (Backup Jobs)

Konfigurasi dilakukan terpusat di Datacenter > Backup > Add:

  • Node: All
  • Storage:pbs-dputr
  • Schedule: Di luar jam kerja kantor (contoh: 01:00 setiap hari).
  • Selection mode: All (atau pilih VM/CT produksi yang diprioritaskan).
  • Mode: Snapshot (memungkinkan backup berjalan tanpa mematikan VM).
  • Notification: Atur pengiriman laporan email jika terjadi kegagalan backup (On failure only atau Always).

6.2 Kebijakan Retensi (Prune), Verifikasi, dan Garbage Collection di PBS

Seluruh pemeliharaan data backup dilakukan langsung pada Web GUI PBS (Datastore > backup-produksi > Prune & GC dan Verify Jobs):

Prune Job

  • Jadwal Rekomendasi: Harian (03:00)
  • Konfigurasi Standar: Keep Daily: 7, Keep Weekly: 4, Keep Monthly: 6
  • Fungsi: Menghapus salinan backup usang secara otomatis sesuai kebijakan retensi.

Garbage Collection (GC)

  • Jadwal Rekomendasi: Mingguan (Minggu, 04:00)
  • Konfigurasi Standar: Otomatis
  • Fungsi: Membebaskan kapasitas disk fisik dari potongan data (chunks) yang tidak lagi terpakai pasca-Prune.

Verify Job

  • Jadwal Rekomendasi: Mingguan (Sabtu, 02:00)
  • Konfigurasi Standar: Re-verify after 30 days
  • Fungsi: Memeriksa integritas checksum seluruh file backup untuk memastikan data tidak korup dan pasti bisa di-restore.

6.3 Prosedur Pemulihan (Restore)

  1. Pemulihan Penuh (Full VM/CT Restore): Buka Node > Storage pbs-dputr > Backups. Pilih titik waktu backup VM/CT yang diinginkan, klik Restore. Tentukan Storage tujuan dan VM ID (gunakan ID baru jika hanya ingin melakukan pengujian tanpa menimpa VM produksi). Klik Restore.
  2. Pemulihan Berkas Tunggal (File-Level Restore): Pada daftar backup di pbs-dputr, pilih backup yang dimaksud lalu klik File Restore. Telusuri direktori di dalam disk VM/CT dan unduh berkas tertentu tanpa perlu memulihkan keseluruhan server.
