Panduan Proxmox VE & Proxmox Backup Server (Bahasa Indonesia)

BAB IV — Instalasi & Integrasi PBS

4.1 Prosedur Instalasi PBS

  1. Lakukan booting server ke-3 menggunakan USB bootable Proxmox Backup Server.
  2. Pilih Install Proxmox Backup Server (Graphical) dan setujui EULA.
  3. Pilih disk khusus Sistem Operasi (pisahkan disk OS dari disk kapasitas besar yang akan digunakan sebagai Datastore backup).
  4. Atur lokasi (Indonesia), zona waktu, kata sandi root, email admin, dan konfigurasi jaringan statis (pbs-server.dputr.local / 192.168.10.13/24).
  5. Selesaikan instalasi dan reboot. Akses Web GUI PBS melalui https://192.168.10.13:8007.

4.2 Konfigurasi Pasca-Instalasi PBS

  1. Buka menu Administration > Repositories. Nonaktifkan repositori pbs-enterprise (jika tanpa lisensi) dan tambahkan repositori No-Subscription.
  2. Buka Administration > Shell, lalu perbarui sistem:
apt update && apt full-upgrade -y

4.3 Pembuatan Datastore Backup

  1. Buka menu Administration > Storage / Disks.
  2. Siapkan disk penyimpanan data backup (disarankan menggunakan ZFS melalui tab ZFS > Create: ZFS dengan konfigurasi RAIDZ1/RAIDZ2 atau Mirror sesuai jumlah disk).
  3. Centang opsi Add as Datastore saat membuat ZFS pool, atau buat manual melalui menu Datastore > Add Datastore (contoh nama datastore: backup-produksi).

4.4 Manajemen Akses Aman (User & API Token)

Demi keamanan (prinsip hak akses minimum), integrasi PVE ke PBS tidak boleh menggunakan akun root. Buat akun khusus backup:

  1. Buka Access Control > User Management > Add: User name: pve-backup | Realm: pbs | Isi kata sandi.
  2. Buka Access Control > API Token > Add: User: pve-backup@pbs | Token name: cluster-token | Hapus centang Privilege Separation (atau atur izin terpisah). Catat dan simpan Secret yang muncul karena hanya ditampilkan satu kali.
  3. Buka Access Control > Permissions > Add > User Permission (dan API Token Permission): Path: /datastore/backup-produksi | User / API Token: pve-backup@pbs (dan tokennya) | Role: DatastoreBackup (memberi hak baca/tulis backup tanpa izin menghapus backup lama secara sembarangan).

4.5 Integrasi PBS ke Cluster Proxmox VE

  1. Ambil Fingerprint PBS: Pada Web GUI PBS, buka Dashboard, klik Show Fingerprint, lalu klik Copy.
  2. Tambahkan Storage di PVE: Pada Web GUI Cluster PVE (pve-node1), buka Datacenter > Storage > Add > Proxmox Backup Server.
  3. Isi parameter berikut:
  1. ID:pbs-dputr
  2. Server:192.168.10.13
  3. Username:pve-backup@pbs!cluster-token
  4. Password:(Masukkan Secret API Token yang telah dicatat)
  5. Datastore:backup-produksi
  6. Fingerprint:(Tempel Fingerprint dari langkah 1)
  7. Nodes:All (otomatis tersedia di Node 1 dan Node 2)
  1. Klik Add. Storage pbs-dputr kini aktif dan siap digunakan oleh seluruh cluster.
