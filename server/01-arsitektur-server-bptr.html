Server & Infrastruktur BPTR (Bahasa Indonesia)

Arsitektur Server BPTR & Docker

Server BPTR adalah satu host Linux yang menjalankan semua aplikasi web Dinas PUPR Provinsi Jambi (e-monev, program/e-proposal, awasi, TTE) sebagai container Docker yang terpisah-pisah. Bab ini menjelaskan spesifikasi server, cara akses, dan daftar lengkap container yang berjalan.

Spesifikasi host

ItemNilai
OSUbuntu 22.04 LTS
CPU4 vCPU
RAM7,6 GB (biasanya ±2 GB terpakai, sisanya cache)
Disk48 GB (volume LVM), rutin terpakai sekitar 50–55%
DockerDocker Engine 29.x + Docker Compose v5 (plugin docker compose, bukan docker-compose lama)

PENTING

Disk cukup pas-pasan (48 GB untuk semua aplikasi + database + image Docker). Build cache Docker yang menumpuk pernah membuat disk sampai 88% penuh. Lihat bab Troubleshooting & Maintenance untuk cara membersihkannya.

Cara akses server

ssh BPTR

Login sebagai user bptr (bukan root). Semua aplikasi ada di /home/bptr/apps/, dikelompokkan per bidang:

  • /home/bptr/apps/bidang-monev/ — e-monev, awasi, TTE (lihat Panduan Aplikasi e-monev)
  • /home/bptr/apps/bidang-program/ — aplikasi program.jambiprov.go.id (admin-panel, proposal, sinkron, backend, database)

Database & akses dari laptop

Kedua database MySQL hanya mendengarkan di alamat internal Docker (172.17.0.1), tidak langsung dibuka ke publik. Untuk mengaksesnya dari laptop (misalnya pakai DBeaver/TablePlus), buat SSH tunnel dulu:

# Database program (programdb)
ssh -L 3310:172.17.0.1:3310 BPTR

# Database e-monev (monevdb)
ssh -L 3311:172.17.0.1:3311 BPTR

Setelah tunnel aktif, koneksi dari laptop ke 127.0.0.1:3310 / 127.0.0.1:3311 seperti biasa. Kredensial database disimpan di file docker-compose.yml masing-masing stack dan di /home/bptr/apps/.secrets-20261103 (mode file 600, hanya root/owner yang bisa baca) — jangan pernah disalin ke chat, commit git, atau dokumen yang bisa diakses orang lain.

Catatan jaringan

Dari dalam server, mengakses domain publik aplikasi sendiri (misalnya curl https://program.jambiprov.go.id) biasanya timeout (hairpin NAT) — ini normal. Untuk tes cepat dari server, akses langsung lewat localhost:<port> sesuai tabel di atas (mis. curl localhost:8080/api/v1/...).

Reverse proxy / TLS untuk domain publik (program.jambiprov.go.id dan subdomain-subdomainnya) tidak berjalan di server BPTR ini — tidak ada nginx/Traefik lokal yang aktif. Routing domain ke port-port di atas diatur di infrastruktur lain (DNS + reverse proxy terpusat, dikelola Diskominfo/pihak jaringan). Lihat bab berikutnya untuk detail pemetaan domain.
