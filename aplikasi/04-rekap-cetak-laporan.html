Panduan Aplikasi e-monev PUPR (Bahasa Indonesia)

Rekap & Cetak Laporan

Setelah realisasi diinput lewat Rekap Bidang, data bisa direkap & dicetak dalam beberapa bentuk laporan. Menu-menu rekap (Rekap Kegiatan, Rekap Dinas, Rekap Pengawas) hanyalah form filter — laporan sesungguhnya dibuka di tab/halaman baru oleh menu Cetak.

PENTING

Semua “Cetak PDF” di aplikasi ini sebenarnya memakai dialog cetak browser (tombol Cetak memanggil window.print()), bukan file PDF yang dibuat otomatis di server. Untuk menyimpan sebagai file PDF, pilih Save as PDF / Simpan sebagai PDF pada dialog cetak browser, bukan printer fisik.

Rekap Per Kegiatan

Menu Rekap Kegiatan punya 3 form:

  1. Cetak Rekap Perkegiatan — filter Bulan, Tahun, Bidang, PPTK, Kegiatan (pilihan PPTK dan Kegiatan saling terhubung), lalu Jenis Cetak (Excel/PDF).
  2. Cetak Rekap Perkegiatan Khusus — filter Bulan, Tahun, dan Tipe sumber dana (DBH/DAK/DAU).
  3. Search Kegiatan — cari kegiatan berdasarkan Bulan, Tahun, Bidang, dan kata kunci Uraian; hasil pencarian otomatis membuka laporan rekap per kegiatan yang sesuai.

Rekap Dinas

Menu Rekap Dinas mencetak rekapitulasi tingkat dinas (gabungan semua bidang) untuk Bulan & Tahun tertentu. Capaian dinas dihitung dengan memberi bobot per bidang, lalu menjumlahkan (bobot × persentase realisasi/target) dari semua bidang.

Rekap Pengawas

Menu Rekap Pengawas punya 3 form cetak:

  1. Cetak Rekap Pengawas (per user pengawas) — filter Bulan, Tahun, User Pengawas.
  2. Cetak Rekap Pengawas By Bidang — filter Bulan, Tahun, Bidang.
  3. Cetak Progress Pengawas By Bidang — filter Bidang saja.

Lihat juga bab Pengawas Lapangan untuk memahami dari mana data ini berasal.

Pengaruh pengaturan “Tampilkan DPAP”

Semua laporan rekap di atas (header, dinas, per kegiatan, per kegiatan khusus) mengikuti pengaturan Tampilkan DPAP pada cetak rekap di menu Setting: jika diaktifkan, laporan memakai angka DPAP (DPA Perubahan/revisi) sebagai ganti DPA biasa. Lihat bab Pengaturan Aplikasi.
