Panduan Aplikasi e-monev PUPR (Bahasa Indonesia)

Pengaturan Aplikasi (Setting)

Menu Setting (biasanya hanya untuk admin) mengatur beberapa nilai global aplikasi.

FieldKeterangan
Nama AplikasiNama yang ditampilkan di aplikasi
AlamatAlamat instansi, ditampilkan di kop laporan
Tampilkan DPAP pada cetak rekapYa/Tidak — jika Ya, semua laporan rekap (lihat bab Rekap & Cetak Laporan) memakai angka DPAP (DPA Perubahan) sebagai ganti DPA biasa
Status input laporanDibuka/Ditutup
Tanggal tutup input (1–32)Tanggal setiap bulan di mana input realisasi ditutup untuk level PPTK

PENTING

Catatan penting: dari pemeriksaan aplikasi saat ini, toggle “Status input laporan” (Dibuka/Ditutup) belum berpengaruh nyata terhadap penguncian input — satu-satunya nilai yang benar-benar mengunci input adalah Tanggal tutup input. Isi 32 pada field tersebut jika ingin input tidak pernah terkunci secara otomatis (karena tidak ada bulan dengan tanggal 32).

Perubahan pada menu ini langsung berlaku untuk seluruh pengguna aplikasi setelah disimpan.
