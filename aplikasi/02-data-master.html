Panduan Aplikasi e-monev PUPR (Bahasa Indonesia)

Data Master: Bidang, Jabatan, Pegawai, Kegiatan & DPA

Sebelum realisasi bisa diinput, data master berikut harus sudah tersedia. Urutan pengisian yang disarankan: Bidang & Jabatan → Pegawai → Kegiatan → Subkegiatan → DPA.

Bidang & Jabatan

Dua menu paling sederhana — hanya satu field nama (Bidang dan Jabatan). Tambah/ubah/hapus seperti data referensi biasa, dan dipakai sebagai pilihan dropdown di menu Pegawai, Kegiatan, dan lainnya.

Pegawai

Menu Pegawai mengisi data pegawai: NIP, Nama, Jabatan (dropdown), Bidang (dropdown). Semua field wajib diisi.

PENTING

Penting — efek otomatis ke akun login:
  • Setiap kali menambah pegawai baru, sistem otomatis membuat akun login baru di menu Users: username = NIP, password default 123456, level = PPTK/operator (level 7).
  • Setiap kali data pegawai diubah, akun login pegawai itu ikut diperbarui (nama & username) — dan password akun tersebut akan ikut di-reset ke 123456. Beri tahu pegawai yang bersangkutan untuk login dan ganti password lagi setelah datanya diedit.

Kegiatan

Menu Kegiatan mencatat kegiatan induk per bidang per tahun. Field form: Kode Rekening, Kegiatan (nama/uraian), Bidang (dropdown — user level PPTK hanya bisa memilih bidangnya sendiri), Tahun. Semua field wajib.

List kegiatan juga bisa dicari (kotak pencarian di atas tabel) dan tampil dengan paginasi. User level PPTK hanya melihat kegiatan milik bidangnya.

Subkegiatan

Menu Subkegiatan merinci kegiatan di atas menjadi sub kegiatan. Form: Kegiatan (dropdown pencarian, format “tahun – nama kegiatan”, otomatis difilter ke bidang sendiri untuk level PPTK), Kode Rekening, Subkegiatan (nama/uraian).

DPA (Dokumen Pelaksanaan Anggaran)

Menu DPA merinci anggaran per item di bawah Subkegiatan — inilah baris yang nanti dipilih sebagai “Uraian DPA” saat input realisasi di Rekap Bidang.

  1. Pilih Bidang → Tahun → Kegiatan → Sub Kegiatan secara berurutan (setiap pilihan memuat ulang pilihan berikutnya lewat AJAX).
  2. Tabel DPA tampil: Kode Rekening, Uraian, Jumlah (pagu), DPAP, Sub Uraian dari (jika item ini adalah rincian dari item DPA lain), tombol Ubah/Hapus.
  3. Tombol Tambah membuka form: Kode Rekening, Uraian*, Jumlah* (nominal rupiah — ketik angka biasa, format titik ribuan otomatis saat mengetik), DPAP (opsional, nominal anggaran perubahan), Sub Uraian dari (opsional — pilih DPA lain sebagai induk, untuk membuat rincian berjenjang; realisasi anak akan otomatis terakumulasi ke induknya, lihat bab Input Realisasi).

PENTING

Hati-hati menghapus DPA yang sudah pernah dipakai untuk input realisasi — sistem tidak menghapus data realisasi terkait secara otomatis, sehingga bisa meninggalkan data realisasi yang “menggantung” (tidak terhubung ke DPA manapun). Pastikan DPA tidak lagi punya realisasi sebelum menghapusnya.
