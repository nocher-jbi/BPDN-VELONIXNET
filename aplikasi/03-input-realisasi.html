Input Realisasi Fisik & Keuangan (Rekap Bidang)

Ini adalah menu utama yang dipakai PPTK/operator setiap bulan: mencatat realisasi fisik (%) dan keuangan (Rp) per item DPA. Menu: Rekap Bidang.

PENTING

Batas waktu input: jika hari ini sudah melewati tanggal tutup input yang diatur admin (menu Setting), level PPTK tidak bisa lagi membuka halaman ini untuk bulan berjalan — akan diarahkan balik ke dashboard dengan notifikasi “penginputan ditutup”. Pastikan input selesai sebelum tanggal tersebut.

Langkah 1 — Pilih Bidang, Bulan & Tahun

Di halaman Rekap Bidang, pilih Bidang, Bulan, dan Tahun yang ingin diisi. Tabel rekap header untuk periode tersebut akan tampil (kolom: PPTK, Bidang, Uraian/Subkegiatan, Periode, siapa & kapan terakhir diubah).

Langkah 2 — Tambah Rekap (header)

Klik Tambah Rekap. PPTK otomatis terisi nama user yang sedang login (tidak bisa diubah). Pilih Uraian = Sub Kegiatan yang mau diisi realisasinya (pilihan sudah difilter ke bidang & tahun yang sedang aktif di filter). Simpan.

Tombol Clone data dari bulan lalu menyalin seluruh rekap header + detail dari bulan sebelumnya ke bulan berjalan, supaya tidak perlu input ulang dari nol setiap bulan. Tidak tersedia untuk bulan Januari atau jika bulan berjalan sudah punya data.

Langkah 3 — Input Detail realisasi

Pada baris header yang sudah dibuat, klik Input Detail, lalu klik Tambah untuk mengisi satu baris realisasi item DPA. Field form:

Setelah disimpan, sistem otomatis menghitung:

  • Deviasi = Realisasi − Target
  • % Penyerapan = Nilai Penyerapan ÷ Dana DPA × 100
  • Sisa Kontrak = Nilai Kontrak − Nilai Penyerapan
  • Sisa Anggaran = Dana DPA − Nilai Penyerapan

Jika item DPA ini adalah rincian dari item DPA lain (field “Sub Uraian dari” terisi saat membuat DPA-nya), sistem otomatis menjumlahkan volume, target, realisasi, dan nilai penyerapan ke item induknya.

Ubah & hapus

Setiap baris detail bisa diubah atau dihapus lewat tombol Pilihan. Menghapus header akan ikut menghapus semua detail di bawahnya — aplikasi akan meminta konfirmasi karena ini tidak bisa dibatalkan.

Khusus admin: tersedia tombol Perbaiki Parent Uraian di tabel detail untuk menghitung ulang agregasi item DPA induk secara manual, berguna jika data akumulasi terlihat tidak sinkron.

Cetak langsung dari halaman ini

Dari halaman filter Rekap Bidang juga tersedia tautan cepat untuk mencetak rekap bidang (PDF/Excel) dan rekap per kegiatan — lihat bab Rekap & Cetak Laporan.
