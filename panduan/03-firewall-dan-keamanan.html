Firewall & Keamanan Router

Mengamankan router supaya tidak mudah diserang dari internet. Ini ringkasan praktis dari bab Securing your router dan Firewall.

Prinsip utama

Firewall input chain melindungi router itu sendiri. Konfigurasi default MikroTik sudah menutup akses manajemen dari WAN (defconf: drop all not coming from LAN). Jangan hapus rule itu.

1. Input chain dasar (router tanpa default config)

/ip/firewall/filter
add chain=input action=accept connection-state=established,related,untracked \
    comment="accept established,related,untracked"
add chain=input action=drop connection-state=invalid comment="drop invalid"
add chain=input action=accept in-interface=ether1 protocol=icmp comment="accept ICMP"
add chain=input action=drop in-interface=ether1 comment="block everything else"

Sesuaikan ether1 dengan interface WAN (kalau PPPoE/LTE, ganti). Salah interface bisa membuat kamu kehilangan akses.

2. Kalau router sudah pakai default config

Tambahkan accept di depan rule defconf dengan place-before:

add chain=input action=accept in-interface-list=WAN protocol=tcp dst-port=8291 \
    comment="allow WinBox" \
    place-before=[find comment="defconf: drop all not coming from LAN"]

3. Hardening checklist

  • Update RouterOS ke versi stabil terbaru
  • Ganti user admin, pakai password ≥12 karakter:
/user/add name=myname password="..." group=full
/user/disable admin
  • Satu akun per admin; pakai SSH key
  • Batasi user ke IP tertentu: /user/set 0 address=192.168.88.0/24
  • Matikan MAC-server:
/tool/mac-server/set allowed-interface-list=none
/tool/mac-server/mac-winbox/set allowed-interface-list=none
/tool/mac-server/ping/set enabled=no
  • Matikan Neighbor Discovery: /ip/neighbor/discovery-settings/set discover-interface-list=none
  • Matikan bandwidth server: /tool/bandwidth-server/set enabled=no
  • Matikan service tak terpakai: /ip/service/disable telnet,ftp,www,api
  • Ganti port SSH & kuatkan kripto:
/ip/service/set ssh port=2200
/ip/ssh/set strong-crypto=yes
  • Matikan proxy/SOCKS/UPnP: /ip/proxy/set enabled=no, /ip/socks/set enabled=no, /ip/upnp/set enabled=no
  • Disable interface yang tidak dipakai

4. Proteksi brute-force SSH

Rule menaikkan sumber lewat 3 address-list, blacklist di koneksi ke-4:

/ip/firewall/filter
add chain=input action=add-src-to-address-list protocol=tcp dst-port=22 \
    connection-state=new in-interface-list=WAN src-address-list=connection3 \
    address-list=bruteforce_blacklist address-list-timeout=1d \
    comment="SSH brute force: blacklist" \
    place-before=[find comment="defconf: drop all not coming from LAN"]
# (lanjut: connection2->connection3, connection1->connection2, first->connection1)
add chain=input action=accept protocol=tcp dst-port=22 in-interface-list=WAN \
    src-address-list=!bruteforce_blacklist comment="SSH brute force: accept" \
    place-before=[find comment="defconf: drop all not coming from LAN"]
add chain=input action=drop protocol=tcp dst-port=22 in-interface-list=WAN \
    comment="SSH brute force: drop blacklisted" \
    place-before=[find comment="defconf: drop all not coming from LAN"]

Peringatan

  • Jangan expose WinBox/SSH ke internet. Pakai VPN (WireGuard) untuk akses jauh.
  • Kalau terpaksa buka dari WAN: password kuat, batasi source address, aktifkan brute-force protection, update terus, dan pantau log.
