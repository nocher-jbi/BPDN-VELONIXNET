Dasar RouterOS & Cara Akses

Panduan singkat untuk pemula: mengenal RouterOS, cara masuk ke router, dan dasar memakai command line. Cocok sebagai langkah pertama sebelum konfigurasi lain.

Apa itu RouterOS

RouterOS adalah sistem operasi jaringan dari MikroTik untuk router, switch, dan access point. Fiturnya: routing, firewall, VPN, wireless, QoS, sampai otomasi.

Versi yang dipakai di buku ini: RouterOS 7.26. Sintaks v7 sedikit berbeda dari v6 — terutama menu /routing dan fitur Bridge VLAN.

Cara masuk ke router

WinBox (GUI, paling ramah)

  1. Unduh WinBox dari mikrotik.com, buka aplikasinya.
  2. Tab Neighbors akan menampilkan router via MAC (tanpa perlu IP).
  3. Klik MAC-nya, login (default user admin, password kosong / sesuai).

SSH (baris perintah)

ssh admin@192.168.88.1

Di CLI, tekan Tab untuk melengkapi perintah dan ? untuk bantuan.

WebFig (browser)

Buka http://192.168.88.1 di browser.

Dasar command line

Setiap perintah dijalankan di menu tertentu, misalnya:

/ip/address/print
/ip/address/add address=192.168.88.1/24 interface=ether2
  • print — tampilkan isi menu
  • add — tambah entri
  • set — ubah entri
  • remove — hapus entri
  • [find ...] — cari entri, mis. remove [find address=192.168.88.1/24]
  • .. — naik satu level, / — ke root

Tips: / di depan = path absolut, jadi aman dijalankan dari mana saja.

Simpan & pindahkan konfigurasi

/export file=backup-config
/system/backup/save name=full-backup
  • /export → skrip teks (bisa dibaca & diedit)
  • /system/backup → backup biner lengkap (untuk restore penuh)

Angka penting

  • /ip/address/print — pastikan IP benar
  • /system/identity/set name=ROUTER-INTI — beri nama router (berguna untuk NOC)
  • /system/clock/set time-zone-name=Asia/Jakarta
