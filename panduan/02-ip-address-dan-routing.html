IP Address, Gateway & Routing Dasar

Mengatur alamat IP, default gateway, dan route statis — fondasi supaya router bisa berkomunikasi ke jaringan lain.

1. Memberi alamat IP ke interface

/ip/address/add address=192.168.88.1/24 interface=ether2
/ip/address/print
  • IP dipasang di interface fisik (ether) atau di bridge kalau portnya sudah jadi member bridge.
  • Kolom actual-interface menunjukkan interface sebenarnya tempat IP terpasang.

2. Menghubungkan dua router langsung (back-to-back)

# Router A
/ip/address/add address=10.10.10.1/30 interface=ether1
# Router B
/ip/address/add address=10.10.10.2/30 interface=ether1

Tes dari Router A: /ping 10.10.10.2

3. Default gateway (route ke internet)

/ip/route/add gateway=192.168.1.1

Kalau WAN pakai DHCP client, gateway biasanya otomatis.

4. Route statis ke jaringan tertentu

/ip/route/add dst-address=10.20.0.0/24 gateway=192.168.88.2

Cek hasil: /ip/route/print where dst-address=10.20.0.0/24

5. Address list (dipakai firewall/BGP)

/ip/firewall/address-list/add list=LAN address=192.168.88.0/24

6. DNS

/ip/dns/set servers=8.8.8.8,1.1.1.1
/ip/dns/set allow-remote-requests=yes

Konsep singkat

  • connected route muncul otomatis saat IP dipasang
  • static route kita tentukan manual
  • dynamic route dari OSPF/BGP/DHCP
  • route dibandingkan lewat distance (makin kecil makin diprioritaskan)

Sering bikin gagal

  • Interface sudah jadi bridge port → pasang IP di bridge, bukan di ether
  • ether1 masih ada DHCP client → bentrok, matikan dulu
  • Lupa gateway → tidak ada jalan keluar ke internet
