Routing: Statis, OSPF & BGP

Ringkasan cara router saling bertukar rute.

1. Static route (paling dasar)

/ip/route/add dst-address=10.20.0.0/24 gateway=192.168.88.2
/ip/route/add dst-address=0.0.0.0/0 gateway=192.168.1.1   # default

Cek: /ip/route/print

2. OSPF (dinamis, dalam satu organisasi)

Menyalakan instance dan menambahkan interface:

/routing/ospf/instance/add name=ospf1
/routing/ospf/area/add name=backbone area-id=0.0.0.0 instance=ospf1
/routing/ospf/interface-template/add networks=10.0.0.0/24 area=backbone

Intent: OSPF otomatis bertukar rute antar router di area yang sama. Cek tetangga: /routing/ospf/neighbor/print

3. BGP (antar-AS, internet)

Menu: /routing/bgp/instance, /routing/bgp/connection, /routing/bgp/session. local.role wajib diisi (ebgp, ibgp, ibgp-rr, atau role RFC 9234).

Contoh eBGP dasar:

/routing/bgp/instance/add name=myInstance as=65531
/routing/bgp/connection/add name=toR2 remote.address=192.168.1.2 \
    instance=myInstance local.role=ebgp

Cek sesi: /routing/bgp/session/print (flag E = established)

Umumkan prefix sendiri (harus ada route match / IGP):

/ip/firewall/address-list/add list=my-nets address=103.x.x.0/24
/routing/bgp/connection/set [find name=toR2] output.network=my-nets

Jebakan BGP (FAQ buku)

  • eBGP ke loopback gagal → set multihop=yes
  • Rute tidak di-advertise ke peer lain → cek output filter / beda instance
  • Best path tidak jalan → hanya berlaku dalam satu instance
  • listen=yes jangan dibuka di link publik tanpa firewall
