PPPoE Server & Client (untuk ISP)

Menyiapkan RouterOS sebagai access concentrator PPPoE untuk pelanggan, dan sebagai client ke upstream.

Bagian A — PPPoE Server (sisi ISP)

1. Pool IP untuk pelanggan

/ip/pool/add name=pppoe-pool ranges=10.10.0.2-10.10.255.254

2. Profile PPP

/ppp/profile/add name=pelanggan local-address=10.10.0.1 remote-address=pppoe-pool \
    dns-server=1.1.1.1,8.8.8.8

3. PPPoE Server di interface

/interface/pppoe-server/server/add service-name=internet interface=bridge1

Bisa juga satu server melayani banyak interface / satu interface banyak server.

4. Akun pelanggan (secrets)

/ppp/secret/add name=pelanggan1 password=Rahasia123 service=pppoe profile=pelanggan

5. Cek sesi aktif

/ppp/active/print
/interface/pppoe-server/server/print

Bagian B — PPPoE Client (ke upstream)

/interface/pppoe-client/add name=pppoe-out1 interface=ether1 \
    user=userISP password=passISP add-default-route=yes use-peer-dns=yes disabled=no

Tambahkan ke interface-list WAN supaya kena NAT/firewall:

/interface/list/member/add list=WAN interface=pppoe-out1

Monitor: /interface/pppoe-client/monitor pppoe-out1 once

Catatan praktis ISP

  • MTU 1492: PPPoE membawa header tambahan; pastikan clamping MSS kalau ada masalah akses halaman tertentu:
/ip/firewall/mangle/add chain=forward protocol=tcp tcp-flags=syn \
    action=change-mss new-mss=1400 tcp-mss=1400-2000 comment="MSS clamp PPPoE"
  • Queue per pelanggan: pakai profile rate-limit atau simple queue.
  • Isolasi: default, PPPoE server tidak meneruskan trafik antar-client.
  • RADIUS: bisa pakai untuk autentikasi terpusat (menu /radius).

Troubleshooting singkat

  • Sesi tidak naik → cek service-name, interface, dan secret/password
  • Pelanggan dapat IP tapi tidak internet → cek NAT, route, dan firewall forward
  • Cek log: /log/print atau filter topik pppoe
