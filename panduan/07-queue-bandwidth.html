Queue & Manajemen Bandwidth

Membatasi dan membagi bandwidth — sering dipakai ISP untuk paket pelanggan.

1. Simple Queue (percepat, per target)

Membatasi trafik per IP/client:

/queue/simple/add name=pelanggan1 target=10.10.0.2/32 \
    max-limit=10M/10M comment="Paket 10 Mbps"
  • max-limit=upload/download
  • target bisa IP, subnet, atau interface.

2. Queue per PPPoE (via profile rate-limit)

/ppp/profile/set [find name=pelanggan] rate-limit="10M/10M"

Lebih rapi untuk banyak pelanggan karena ikut sesi PPPoE.

3. Queue Tree (kontrol per kelas trafik)

Butuh mangle untuk menandai trafik dulu:

/ip/firewall/mangle/add chain=forward action=mark-packet \
    new-packet-mark=web passthrough=no protocol=tcp dst-port=80,443
/queue/tree/add name=web parent=global packet-mark=web max-limit=50M

4. PCQ (bagi rata otomatis antar client)

Cocok untuk hotspot/RT-RW net:

/queue/type/add name=pcq-down kind=pcq pcq-rate=0 pcq-classifier=dst-address
/queue/simple/add name=download target=192.168.0.0/16 \
    max-limit=100M queue=pcq-down/pcq-down

pcq-rate=0 artinya pembagian otomatis dari total.

Konsep

  • Simple Queue: paling gampang, urutannya: dari paling spesifik ke umum.
  • Queue Tree: kontrol detail per kelas, butuh mangle.
  • PCQ: pembagian dinamis per client.

Tips

  • Ukuran burst bisa membantu trafik sesaat: burst-limit, burst-time
  • Untuk hulu (upload), queue bekerja di interface keluar — perhatikan arah.
  • Monitor: /queue/simple/print stats
