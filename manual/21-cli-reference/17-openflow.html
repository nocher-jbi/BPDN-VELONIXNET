openflow

This menu lists the configuration of OpenFlow clients.

openflow

Package: openflow Type: Directory

This menu lists the configuration of OpenFlow clients.

Flag / Name / Description

  • X disabled — The entry is disabled.

Argument / Type / Description

  • name string — Reference name of the entry
  • datapath-id super { number: num [0 .. 65535] , [mac-address] /macAddr } — Datapath ID consisting of two parts (integer number [0..65535] and MAC address) separated by a slash.
  • version enum (default | 1 | 1.3) — Version of the OpenFlow standard to be used. - default (default) - agreed with the controller; with Faucet this is 1.3. - 1 - OpenFlow 1.0. - 1.3 - OpenFlow 1.3.
  • passive-port num — The port on which the OpenFlow agent listens for connections from the controller. Default: disabled.
  • controllers object { contr: super { controler-protocol: enum (tcp | tls) , [controller-address] /ip6Addr , [controller-port] /num [1 .. 65535] } } — Configuration of the connection to the controller. Supported protocols are tcp and tls. Example: tcp/1.2.3.4/6654.
  • certificate enum (none) — Certificate from certificate store. Used together with the verify-peer parameter.
  • verify-peer enum (required | none | if-cert-present) — Verify peer's identity against the router's certificate store.
  • isolate-controllers bool — Whether to isolate the configured controllers from each other.

Read-only Argument / Type / Description

  • openflow-fast-path-packets num — Number of packets sent to fast path.
  • openflow-fast-path-bytes num — Number of bytes sent to fast path.

flow

This menu lists the installed flows responsible for packet forwarding between OpenFlow ports.

openflow/flow

Package: openflow Type: Directory

This menu lists the installed flows responsible for packet forwarding between OpenFlow ports.

Flag / Name / Description

  • I inactive — The entry is inactive.

Read-only Argument / Type / Description

  • switch enum — Controller name that installed the rule.
  • version num — OpenFlow protocol version of the switch that installed the flow.
  • match string — Match fields the flow entry matches against.
  • actions string — Actions applied to packets that match the flow entry.
  • info string — Additional flow entry information, such as priority, timeouts, and cookie.
  • table-id num — ID of the table where the rule is located.
  • bytes num — Number of bytes matched by the rule.
  • packets num — Number of packets matched by the rule.
  • duration time — Time since the flow entry was installed.

group

RouterOS directory reference for /openflow/group.

openflow/group

Package: openflow Type: Directory

Flag / Name / Description

  • I inactive — The entry is inactive.

Read-only Argument / Type / Description

  • switch enum — Controller name that installed the group.
  • id num — Identifier of the group.
  • type enum (all | select | indirect | ff) — Group type that determines how the action buckets are processed: all, select, indirect, or fast failover.
  • bucket-count num — Number of action buckets in the group.
  • flow-count num — Number of flow entries that reference the group.
  • buckets string — List of action buckets in the group.
  • bytes num — Number of bytes processed by the group.
  • packets num — Number of packets processed by the group.
  • duration time — Time since the group was installed.
  • bucket-stats string — Per-bucket packet and byte statistics.

meter

The sub-menu lists the traffic meters installed by the controller. Meters enable rate monitoring before output and applying action instructions.

openflow/meter

Package: openflow Type: Directory

The sub-menu lists the traffic meters installed by the controller. Meters enable rate monitoring before output and applying action instructions.

Flag / Name / Description

  • I inactive — The entry is inactive.

Read-only Argument / Type / Description

  • switch enum — Controller name that installed the meter.
  • id num — Identifier of the meter.
  • band-count num — Number of meter bands in the meter.
  • bands string — List of meter bands that define the rate and how packets are processed.
  • bytes num — Number of bytes processed by the meter.
  • packets num — Number of packets processed by the meter.
  • duration time — Time since the meter was installed.

port

This menu lists the ports controlled by OpenFlow.

openflow/port

Package: openflow Type: Directory

This menu lists the ports controlled by OpenFlow.

Flag / Name / Description

  • X disabled — The entry is disabled.
  • I inactive — The entry is inactive.
  • D dynamic — The entry is dynamic.

Argument / Type / Description

  • interface enum () — Name of the interface to be controlled by OpenFlow.
  • switch enum — Name of the switch able to control the port.
  • port-id num — Port ID used to identify the interface in flow rules.

Read-only Argument / Type / Description

  • tx-bytes num — Number of bytes transmitted on the interface.
  • tx-packets num — Number of packets transmitted on the interface.
  • rx-bytes num — Number of bytes received on the interface.
  • rx-packets num — Number of packets received on the interface.
