user-manager

General settings of User Manager, the RADIUS server of RouterOS.

user-manager

Package: userman-5 Type: Settings Directory

General settings of User Manager, the RADIUS server of RouterOS.

Argument / Type / Description

  • enabled bool — Enables User Manager. Default: no.
  • authentication-port num — UDP port for authentication requests. Default: 1812.
  • accounting-port num — UDP port for accounting requests. Default: 1813.
  • certificate enum (none) — Server certificate for the EAP methods that use TLS (EAP-TLS, EAP-TTLS, EAP-PEAP). Default: none.
  • radsec-certificate enum (none) — Server certificate for routers that connect with RadSec. Default: none.
  • use-profiles bool — Uses profiles and limitations. With yes, a user without a valid profile is refused. With no, a user needs only a name and a password. Default: no.
  • require-message-auth enum (no | yes-access-request) — Whether an Access-Request must have the Message-Authenticator attribute: yes-access-request or no. Default: yes-access-request.

user-manager/advanced

Package: userman-5 Type: Settings Directory

Settings of the web pages and of payments with PayPal.

Argument / Type / Description

  • paypal-allow bool — Lets users buy profiles with PayPal on the web page. Default: no.

  • paypal-signature string — Signature of the PayPal API account.
  • paypal-currency string — Currency of the price of the profiles. Default: USD.

attribute

user-manager/attribute

Package: userman-5 Type: Directory

RADIUS attributes that User Manager can send to a router. Users and groups name them in attributes.

Flag / Name / Description

  • ***** default — Predefined attribute.

Argument / Type / Description

  • vendor-id enum (standard | Cisco | Microsoft | Mikrotik) { standard:0, Cisco:9, Microsoft:311, Mikrotik:14988 } — Vendor number of the attribute, or one of the names standard, Mikrotik, Microsoft, Cisco. Default: standard.

  • standard-name string — Name of the attribute in the RADIUS dictionary, when the vendor and the number are known.

limitation

Sets of limits for profiles: speed, traffic and time. A limitation is connected to a profile in /user-manager/profile-limitation. The traffic and time limits count all sessions of a user together and are checked when...

user-manager/limitation

Package: userman-5 Type: Directory

Sets of limits for profiles: speed, traffic and time. A limitation is connected to a profile in /user-manager/profile-limitation. The traffic and time limits count all sessions of a user together and are checked when the router sends accounting updates.

Argument / Type / Description

  • name string — Name of the limitation.
  • download-limit num — Bytes that a user can download. Default: 0 (no limit).
  • upload-limit num — Bytes that a user can upload. Default: 0 (no limit).
  • transfer-limit num — Bytes that a user can download and upload together. Default: 0 (no limit).
  • uptime-limit time — Time that a user can be connected. Default: 0s (no limit).
  • reset-counters-start-time date — Date and time from which reset-counters-interval is counted.
  • reset-counters-interval alt { constant: enum (disabled | hourly | daily | weekly | monthly) , reset-counters-interval: time } — How often the counters of the users are cleared: hourly, daily, weekly, monthly or disabled. Default: disabled.
  • rate-limit-rx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: the speed that the router receives from the user (upload), in bits per second.
  • rate-limit-tx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: the speed that the router sends to the user (download), in bits per second.
  • rate-limit-burst-rx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst rate for upload.
  • rate-limit-burst-tx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst rate for download.
  • rate-limit-burst-threshold-rx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst threshold for upload.
  • rate-limit-burst-threshold-tx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst threshold for download.
  • rate-limit-burst-time-rx time — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst time for upload.
  • rate-limit-burst-time-tx time — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: burst time for download.
  • rate-limit-min-rx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: guaranteed rate (limit-at) for upload.
  • rate-limit-min-tx num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: guaranteed rate (limit-at) for download.
  • rate-limit-priority num — Part of the rate limit that is sent in the Mikrotik-Rate-Limit attribute: priority of the queue.

Plans for users. Used with use-profiles=yes in /user-manager. A profile is given to a user in /user-manager/user-profile.

Package: userman-5 Type: Directory

Plans for users. Used with use-profiles=yes in /user-manager. A profile is given to a user in /user-manager/user-profile.

Argument / Type / Description

user

Users of User Manager.

user-manager/user

Package: userman-5 Type: Directory

Users of User Manager.

Flag / Name / Description

  • X disabled — Disabled. The user cannot log in.

Argument / Type / Description

  • name string — Name of the user.
  • password string — Password of the user.
  • otp-secret string — Key for time-based one-time passwords, in Base32 format. When set, the user must add the current six-digit code to the password. A code works for one login.
  • group enum — Group of the user. Default: default.
  • shared-users enum (unlimited) { unlimited:0 } — Number of simultaneous sessions, or unlimited. At the limit, a new login is refused and the oldest session is disconnected. Default: 1.
  • caller-id enum (bind) — Allows the login only when the Calling-Station-Id of the request has this value.
  • attributes object { attribute-value: super { attribute: enum , [value] :string } } — Attributes that are sent in the Access-Accept for the user, as Name:value separated with commas.
