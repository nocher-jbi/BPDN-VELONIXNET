radius

Type: Directory

RADIUS servers that the router services use for authentication and accounting. The entries are used in the order of the list. See RADIUS for the full guide.

Flag / Name / Description

  • X disabled — The entry is disabled and is not used.

Argument / Type / Description

  • service ubit (ppp, login, hotspot, wireless, dhcp, ipsec, dot1x) — Router services that use this server. Each service also has its own setting that turns RADIUS on. - ppp - PPP servers. - login - Router users. - hotspot - HotSpot. - wireless - Wireless client authentication. - dhcp - DHCP server. The MAC address of the device is sent as User-Name. - ipsec - IPsec client authentication. - dot1x - Dot1X.
  • called-id string — The entry is used only for requests with this Called-Station-Id. For PPPoE it is the service name, for PPTP and L2TP the IP address of the server. An empty value matches every request. Default: empty.
  • domain string — The entry is used only for users with this domain in the login name (DOMAIN\name or name@domain). An empty value matches every user. Default: empty.
  • address address (flags=46v) — IPv4 or IPv6 address of the RADIUS server. With an IPv6 address the router sends NAS-IPv6-Address in place of NAS-IP-Address. To reach the server in a VRF, add the VRF name: address@vrf.
  • secret string — Shared secret of the router and the server. Not used with protocol=radsec. This is a sensitive parameter.
  • authentication-port num — UDP port of the server for authentication requests. Not used with protocol=radsec. Range: 1..65535. Default: 1812.
  • accounting-port num — UDP port of the server for accounting requests. Not used with protocol=radsec. Range: 1..65535. Default: 1813.
  • timeout time — Time to wait for an answer before the request is sent again. Default: 1100ms.
  • radsec-timeout time — Time to wait for an answer before the request is sent again over RadSec. Default: 3300ms.
  • accounting-backup bool — Whether the server gets a copy of the accounting requests. - no (default) - The entry is used for authentication and accounting in the order of the list. - yes - The entry gets a copy of every accounting request of its services, in addition to the entry that answers. It gets no authentication requests.
  • realm string — Value of the Mikrotik-Realm attribute in the Access-Requests of the entry. Without it, the attribute has the domain of the user name, and it is not sent when the name has no domain. Default: empty.
  • src-address alt { ip-address: ipAddr , ipv6-address: ip6Addr } — Source IPv4 or IPv6 address of the packets sent to the server. The same address is sent as NAS-IP-Address. Default: not set, the router selects the address.
  • protocol enum (udp | radsec) — Transport of the requests. - udp (default) - RADIUS over UDP, to authentication-port and accounting-port. - radsec - RADIUS over TLS, to TCP port 2083. Needs certificate.
  • certificate enum (none) { none:0 } — Client certificate, with its private key, for protocol=radsec. The certificate authority of the server must be a trusted certificate on the router, and the certificate of the server must contain the value of address. Default: none.
  • require-message-auth enum (no | yes-for-request-resp) — Whether an answer to an Access-Request must have the Message-Authenticator attribute. The router adds the attribute to every Access-Request with either value. - yes-for-request-resp (default) - An answer without the attribute is dropped and counted in bad-replies. - no - An answer without the attribute is accepted.

Read-only Argument / Type / Description

  • status string — Last connection error of the entry, for example error: Connection refused. With protocol=radsec, the state of the TLS connection: connecting, performing TLS handshake, TLS connected, or an error such as connect:Connection refused or client certificate required.

incoming

Settings for the Disconnect and Change of Authorization (CoA) requests that RADIUS servers send to the router. See RADIUS for the full guide.

radius/incoming

Type: Settings Directory

Settings for the Disconnect and Change of Authorization (CoA) requests that RADIUS servers send to the router. See RADIUS for the full guide.

Argument / Type / Description

  • accept bool — Whether the router accepts Disconnect and CoA requests. The request must be signed with the shared secret of a /radius entry. Default: no.
  • port num — UDP port on which the router listens for the requests. Default: 3799.
  • vrf enum — VRF in which the router listens for the requests. Requests that arrive in another VRF are not answered. Default: main.

monitor

Shows the counters of the Disconnect and CoA requests. See RADIUS for the full guide.

radius/incoming/monitor

Type: Command

Shows the counters of the Disconnect and CoA requests. See RADIUS for the full guide.

Read-only Argument / Type / Description

  • requests num — Valid requests received.
  • bad-requests num — Requests dropped because of a wrong signature.
  • acks num — Requests answered with Disconnect-ACK or CoA-ACK.
  • naks num — Requests answered with Disconnect-NAK or CoA-NAK, for example when no session matches.

reset-counters

Sets the counters of the Disconnect and CoA requests to zero.

radius/incoming/reset-counters

Type: Command

Sets the counters of the Disconnect and CoA requests to zero.

monitor

Shows the request counters of one entry. See RADIUS for the full guide.

radius/monitor

Type: Command

Shows the request counters of one entry. See RADIUS for the full guide.

Read-only Argument / Type / Description

  • pending num — Requests that wait for an answer.
  • requests num — Requests sent to the server, without the resent ones.
  • accepts num — Access-Accept and accounting answers received.
  • rejects num — Access-Reject answers received.
  • challenges num
  • accounting-responses num
  • other-replies num
  • resends num — Requests sent again after timeout.
  • timeouts num — Requests that got no answer after all tries.
  • bad-replies num — Answers that were dropped: a wrong signature, or no Message-Authenticator while require-message-auth asks for it.
  • last-request-rtt time — Time between the last request and its answer.

reset-counters

Sets the counters of all /radius entries to zero.

radius/reset-counters

Type: Command

Sets the counters of all /radius entries to zero.
