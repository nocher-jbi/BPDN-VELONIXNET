file

Type: Directory

The /file menu lists user files on the router's storage and manages them: creating, editing, copying and deleting files and directories. For an uploaded RouterOS .npk file, the menu also shows package details, such as the architecture and build time. Files and directories shared through File Share (Back To Home) are marked with the shared flag and have a url property with the share link. See the Files guide.

Flag / Name / Description

  • S shared — The file or directory is shared through File Share (Back To Home).

Argument / Type / Description

  • name file — Name of the file or directory, including the path. A leading / is optional.
  • type enum (file | directory) — Type of the entry. Default: file.
  • contents string — The actual content of the file. Limited to just under 60 KiB (61439 bytes): creating a file with longer contents fails, and files larger than that return nothing here. Use /file/read to read larger files.

Read-only Argument / Type / Description

  • size num — File size in bytes.
  • last-modified date — Time when the file was created or last modified.
  • package-name string — Name of the installable package. Applies only to RouterOS .npk files.
  • package-version string — Version of the installable package. Applies only to RouterOS .npk files.
  • package-build-time date — Time when the package was built. Applies only to RouterOS .npk files.
  • package-architecture string — Architecture that the package is built for. Applies only to RouterOS .npk files.
  • url string — URL for cloud VPN file sharing. Shown for files and directories shared through File Share (Back To Home).

read

Reads a chunk of a file's contents and returns it as a string in data. Works with files of any size, unlike the contents property, which is limited to just under 60 KiB. See the Files guide.

file/read

Type: Command

Reads a chunk of a file's contents and returns it as a string in data. Works with files of any size, unlike the contents property, which is limited to just under 60 KiB. See the Files guide.

Argument / Type / Description

  • file file — Name of the file to read.
  • chunk-size num — Chunk size to read from the file. Required. Range: 1..32768.
  • offset num — Offset where to start reading the file. A chunk that continues past the end of the file is shortened; an offset past the end fails.

Read-only Argument / Type / Description

  • data string — The read data returned as a string.

sync

RouterOS directory reference for /file/sync.

file/sync

Package: rose-storage Type: Directory

Flag / Name / Description

  • X disabled — The sync entry is disabled.
  • I invalid — The entry is invalid, for example it references a missing or unusable path.
  • D dynamic — The entry is created automatically.

Argument / Type / Description

  • remote-address multi { array-id, address: string } — IP address of the remote RouterOS device to synchronize with. The remote device must have the rsync daemon enabled (rsync-daemon).
  • mode enum (upload | download) — Direction of the synchronization: - upload - send the local-path file or folder to the remote device. - download - fetch remote-path from the remote device to this router.
  • local-path file — File or folder path on this router; the source for mode=upload and the destination for mode=download.
  • remote-path string — File or folder path on the remote device.
  • user string — RouterOS user on the remote device used for authentication.
  • password string — Password of the user on the remote device. When it is set, the transfers run over automatically created IPsec.

Read-only Argument / Type / Description

  • status string — Status of the synchronization, for example in sync, making control connection to <ip> or initializing transfer.

import

Type: Command

Runs a script file (.rsc) line by line, for example a configuration made with export. The import adds to the existing configuration and stops at the first line that fails; the lines before it stay applied. See Configuration Management.

Argument / Type / Description

  • file-name file — Script file to run.
  • from-line num — Starts the import at this line of the file. Works only with verbose=yes; without it, the router warns from-line parameter does not work for non-verbose import and runs the whole file.
  • verbose enum (no | yes | progress) — With yes, prints each line with its number (#line N) before it runs, so the output shows where the import stops. With no, runs the file without printing the lines.
  • dry-run switch — Checks the file without changing the configuration and reports No syntax errors found in the import file when it finds none. Works only with verbose=yes; without it, the import fails with dry-run parameter cannot be used in non-verbose mode.
