certificate

RouterOS directory reference for /certificate.

certificate

Type: Directory

Flag / Name / Description

  • K private-key — private-key
  • L crl — crl
  • C smart-card-key — smart-card-key
  • A authority — authority
  • I issued — issued
  • R revoked — revoked
  • E expired — expired
  • T trusted — trusted
  • a acme-managed — acme-managed
  • D dynamic — dynamic

Argument / Type / Description

  • active switch
  • inactive switch
  • name string — Name of the certificate or template in the store.
  • pem string — import certificate or unencrypted private key from a pasted PEM string
  • trust-store alt { all: enum (all) , component: ubit (ipsec, wpa-eap, capsman, fetch, sstp, ovpn, mqtt, email, netwatch, radius, container, userman, lora, wiliot, openflow, tr069, dot1x, dns, www, api, reverse-proxy, logging) } — Services that use the certificate as a trusted authority. Default: all.
  • digest-algorithm enum (md5 | sha1 | sha256 | sha384 | sha512) — Hash algorithm of the certificate signature. Default: sha256.
  • trusted bool — Whether services trust the certificate as an authority. A self-signed authority created on the router and an imported certificate are trusted by default. A certificate issued by an authority on the router is not.
  • common-name string — Common name (CN) of the subject.
  • organization string
  • unit string
  • locality string
  • state string
  • country string
  • subject-alt-name object { alt-name: composite { type: enum (IP | DNS | email) , value: alt { ip: alt { ipv6: ip6Addr , ip: ipAddr } , string: string } } } — Subject alternative names as a list of DNS:, IP: and email: entries, for example DNS:router.example.com,IP:192.168.88.1.
  • key-size enum (prime256v1 | secp384r1 | secp521r1 | 1024 | 1536 | 2048 | 4096 | 8192) { 1024:1024, 1536:1536, 2048:2048, 4096:4096, 8192:8192 } — RSA key size in bits, or the name of an elliptic curve for an EC key. Default: 2048.
  • key-usage ubit (digital-signature, content-commitment, key-encipherment, data-encipherment, key-agreement, key-cert-sign, crl-sign, encipher-only, decipher-only, tls-server, tls-client, code-sign, email-protect, timestamp, ocsp-sign, dvcs) — Allowed uses of the key. Default: digital-signature,key-encipherment,data-encipherment,key-cert-sign,crl-sign,tls-server,tls-client.
  • days-valid num — Number of days the certificate is valid from the time it is signed. Default: 365.

Read-only Argument / Type / Description

  • ca-crl-host string — Host where this authority publishes its certificate revocation list.
  • ca enum — Authority on this router that issued the certificate.
  • scep-url string — URL of the SCEP server the certificate was enrolled from.
  • fingerprint string
  • req-fingerprint string
  • ca-fingerprint string
  • expires-after time — Time left until the certificate expires.
  • challenge-password string
  • domain-names string — Domain names of the ACME certificate.
  • directory-url string — Directory URL of the ACME authority.
  • acme-status string — State of the ACME client. For an issued certificate, the time of the next renewal.
  • revoked date — Time when the certificate was revoked.
  • status string — State of the SCEP client.
  • issuer multi { array-id, issuer: string } — Subject of the authority that issued the certificate.
  • key-type enum (rsa | dsa | ec) — Type of the key.
  • invalid-before date — Start of the validity time.
  • invalid-after date — End of the validity time.
  • serial-number string — Serial number of the certificate.
  • akid string — Authority key identifier: the subject key identifier of the issuer.
  • skid string — Subject key identifier.

export-certificate

RouterOS command reference for /certificate/export-certificate.

certificate/export-certificate

Type: Command

Argument / Type / Description

  • export-passphrase string — Passphrase that encrypts the exported private key. Without it, only the certificate is exported.
  • type enum (pem | pkcs12) — Format of the export. - pem (default) - A .crt file with the certificate and, with export-passphrase, a .key file with the encrypted private key. - pkcs12 - One .p12 file with the certificate, its private key and the certificate of the authority.
  • file-name file — Name of the exported files without the extension. Default: cert_export_<certificate name>.
