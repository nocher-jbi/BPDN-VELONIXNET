network

RouterOS directory reference for /app/network.

app/network

Syscap: app Package: container Type: Directory

Flag / Name / Description

  • e external — The network is an existing bridge or the LAN bridge.
  • I invalid — The network configuration is invalid.

Argument / Type / Description

  • name string — Network name. internal is the app-created network; external networks use the bridge name and the lan alias.
  • allow-outgoing-access bool — Whether apps on the network can reach destinations outside it. Default: yes.

Read-only Argument / Type / Description

  • network ipAddr — Network address of the app-created internal network.
  • ip ipAddr — Router IP address on the network.
  • status string — Current network state, such as ready.
  • used-ips multi { array-id, array-id, ip-and-name: composite { ip: ipAddr , name: string } } — IP addresses allocated on the network and the app or host that uses each one.
  • bridge-interface iface_enum { none } — Bridge interface that carries the network.
  • cmds multi { cmd: string } — Commands that RouterOS used to create the network.

settings

RouterOS settings reference for /app/settings.

app/settings

Syscap: app Package: container Type: Settings Directory

Argument / Type / Description

  • disk enum (none) — Disk used for app images, data, and downloads. The setup wizard sets it. Default: none.
  • router-ip ipAddr — IP address at which clients reach the router. Apps use it in generated URLs and port-forwarding rules. Default: none. An app enabled without it waits with status=waiting for router ip to be configured.
  • lan-bridge iface_enum { none } — Bridge used as the LAN. Apps whose default network is lan attach their VETH interface to it. Default: none.
  • media-path file — Directory for app media files. Default: none; RouterOS uses assumed-media-path.
  • download-path file — Directory for downloaded app content. Default: none; RouterOS uses assumed-download-path.
  • show-in-webfig bool — Whether WebFig shows links to enabled apps on the login page. Default: yes.
  • auto-update bool — Default automatic update setting for installed apps. Each app can override it with its own auto-update property. Default: no.
  • registry-mirrors multi { array-id, array-id, src-and-dst: composite { src: string , dst: string } } — Registry mirror mappings in source:destination form, for example *:mirror.example.com to use one mirror for every registry. Default: none.
  • app-store-urls multi { array-id, app-store-url: string } — URLs of custom app stores. Each URL must return a YAML array of app definitions. Default: none.

Read-only Argument / Type / Description

  • assumed-router-ip ipAddr — Automatically detected router IP address, when available.
  • assumed-lan-bridge iface_enum { none } — Automatically detected LAN bridge, when available.
  • assumed-media-path file — Default media directory on the selected app disk.
  • assumed-download-path file — Default download directory inside the media directory.
  • certificate-status string — Status of the certificate used for app HTTPS URLs. ok means the certificate is usable.
  • certificate enum (none) — Name of the certificate used for app HTTPS URLs.
