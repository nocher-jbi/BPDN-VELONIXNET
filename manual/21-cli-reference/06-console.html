RouterOS command reference for /console/inspect.

console/inspect

Type: Command Returns the command tree, built-in help, tab-completion candidates and syntax highlighting data that the console uses. Scripts and tools use it to discover menus, commands, arguments and value types, or to check a command line before running it. For request details and examples, see Console inspect.

Argument / Type / Description

  • request ubit (self, child, completion, highlight, syntax, error) — Request to perform. Combine values with commas, for example child,completion. Each returned row has a type field that names the request that produced it.
  • path multi { name: string } — Menu or command path as a comma-separated list of names, for example ip,address,add. Omit it for the root menu. Do not use slashes or a leading slash.
  • input string — Command line to analyze for completion, highlight, and syntax requests. Use an absolute path such as /ip/address/print, or a path relative to path.

Read-only Argument / Type / Description

  • type enum (self | child | completion | highlight | syntax | error) — Request that produced the row: self, child, completion, highlight, syntax, or error.
  • name string — Name of the menu, command, or argument. Returned for self and child rows.
  • node-type enum (path | dir | cmd | arg) — Kind of node: path for a top-level menu path, dir for a menu directory, cmd for a command, and arg for an argument.
  • completion string — Text to insert for a completion candidate.
  • style enum (none | syntax-meta | syntax-nonterminal | syntax-value | syntax-obsolete | error | ambiguous | comment | escaped | variable | variable-undefined | variable-global | variable-local | variable-auto | variable-parameter | dir | cmd | arg | arg-scope | arg-dot | obj-disabled | obj-inactive | obj-dynamic | obj-running | obj-wildcard | obj-decode-error | about | prompt-nosafe | prompt-safe | prompt-user | prompt-host | prompt-path | prompt-hotlock | line-more | line-number | hud-key | flag-title | flag-hints | flag | brief-header | detail-arg-name | detail-arg-equals | gradient-0 | gradient-1 | gradient-2 | gradient-3 | gradient-4 | gradient-5 | gradient-6 | gradient-7) — Style class of a completion candidate or of a highlighted character. Common values are dir, cmd, arg, none, and syntax-meta. The values error, obj-inactive, and syntax-obsolete mark input the console cannot use.
  • offset num — Zero-based character position in input where the completion applies or where the highlighted character starts.
  • preference num — Ordering weight of a completion candidate. Higher values are offered before lower values.
  • show bool — Whether the completion candidate appears in the interactive Tab list.
  • highlight multi { style: enum (none | syntax-meta | syntax-nonterminal | syntax-value | syntax-obsolete | error | ambiguous | comment | escaped | variable | variable-undefined | variable-global | variable-local | variable-auto | variable-parameter | dir | cmd | arg | arg-scope | arg-dot | obj-disabled | obj-inactive | obj-dynamic | obj-running | obj-wildcard | obj-decode-error | about | prompt-nosafe | prompt-safe | prompt-user | prompt-host | prompt-path | prompt-hotlock | line-more | line-number | hud-key | flag-title | flag-hints | flag | brief-header | detail-arg-name | detail-arg-equals | gradient-0 | gradient-1 | gradient-2 | gradient-3 | gradient-4 | gradient-5 | gradient-6 | gradient-7) } — Style of each character in input, in order. Returned by the highlight request.
  • symbol string — Name of the symbol described by a syntax row, for example an argument name or a value type.
  • symbol-type enum (collection | explanation | definition) { collection:0, explanation:1, definition:2 } — Role of the symbol in the syntax output: collection for the containing list, explanation for menu, command, and argument help, or definition for a value type.
  • nested num — Nesting level of a syntax row. The collection row is 0, and its entries start at 1.
  • nonorm bool — Console-internal flag. The collection row sets it to true.
  • text string — Description, help text, or value type description.

settings

RouterOS settings reference for /console/settings.

console/settings

Type: Settings Directory

Argument / Type / Description

  • sanitize-names bool — Replaces reserved characters (\ / : * ? |) with underscores in file and script names. Default: no.
  • log-script-errors bool — Writes errors of scripts that run in the background to the log. Default: yes.
  • tab-width num — Tab width in the full-screen editor. Default: 4.
