snmp

Type: Settings Directory

The /snmp menu turns the SNMP agent on and sets its general behavior: the engine ID that identifies the router to SNMPv3 clients, the address and VRF it answers on, and how traps are sent. The agent is off by default. The communities that may actually read or write are defined in the /snmp/community menu. See the SNMP guide for configuration examples.

Argument / Type / Description

  • enabled bool — Whether the SNMP agent answers queries and sends traps. Default: no.
  • contact string — Administrative contact information, readable by any collector. Default: empty.
  • location string — Administrative location information, readable by any collector. Default: empty.
  • engine-id-suffix string — Tail of the agent's SNMP engine ID. The router builds the full engine ID from the prefix 80003a8c04 and the given value written as ASCII hex; for example the suffix 1234 produces the engine ID 80003a8c0431323334. Leave the suffix empty to use the automatically generated engine ID, which is different on each router and stays the same across reboots. Default: empty.
  • src-address alt { ip: ipAddr , ip6: ip6Addr } — Source address for SNMP messages. With a value set, the agent answers only requests addressed to that address, and an IPv4 value stops it answering IPv6 requests. Default: :: - replies come from the address of the interface that received the request.
  • trap-target object { ip-addresses: alt { ipv6: ip6Addr , ip: ipAddr } } — List of collector addresses that receive SNMP traps; traps go to UDP port 162 on each address. Default: empty.
  • trap-community enum — Community used to send traps. It must exist in the /snmp/community menu; its security level decides how the trap is protected. Default: public.
  • trap-version enum (1 | 2 | 3) { 1:0, 2:1, 3:3 } — Version of the trap protocol. - 1 (default) - SNMPv1 trap. - 2 - SNMPv2c trap. - 3 - SNMPv3 trap, using the authentication and encryption of the trap-community.
  • trap-generators multi { array-id, generator: enum } — Events that generate a trap; several values can be combined. - interfaces - A linkDown/linkUp trap when an interface changes state; narrow this with trap-interfaces. - start-trap - A trap when the SNMP service starts. - temp-exception (default) - A trap when the CPU temperature reaches the /system/health threshold.
  • trap-interfaces object { interface: iface_enum } — List of interfaces whose state changes generate interfaces traps; other interfaces stay quiet. Empty means any interface. Default: empty.
  • vrf enum — VRF the SNMP agent runs in. Requests that arrive in other VRFs get no reply. Default: main.

Read-only Argument / Type / Description

  • engine-id string — Full SNMP engine ID of the agent: the prefix 80003a8c04 followed by the engine-id-suffix value written as ASCII hex, or the automatically generated ID when the suffix is empty. SNMPv3 clients address the agent by this value and include it in every request.

snmp/community

Type: Directory

The /snmp/community menu defines the SNMP communities: what each of them may read or write, from which addresses, and under which security level. The community name works as the password for SNMPv1 and v2c and as the security name for SNMPv3. A request that does not match a community (wrong name or wrong source address) gets no reply at all. See the /snmp reference for the agent settings and the SNMP guide for examples.

Flag / Name / Description

  • ***** default — Default community. The router is created with one community, public, with read access from any address, until you change or remove it.
  • X disabled — Disabled community. A disabled community does not answer requests; new communities are created enabled.

Argument / Type / Description

  • name string — Name of the community. For SNMPv1 and v2c it travels in clear text with every packet and works as the password; for SNMPv3 it is the security name. Default: public.
  • addresses object { address: alt { ipv6: ip6Prefix , ip: ipPrefix } } — Source addresses or prefixes allowed to use this community. A request from any other address gets no reply. Default: ::/0 (any address).
  • security enum (none | authorized | private) { none:0, authorized:1, private:2 } — Security level the community requires. - none (default) - No authentication and no encryption (noAuthNoPriv); the community name alone grants access. - authorized - SNMPv3 authentication required (authNoPriv); v1 and v2c requests are not answered. - private - SNMPv3 authentication and encryption required (authPriv); v1 and v2c requests are not answered.
  • read-access bool — Whether requests may read MIB values. Default: yes.
  • write-access bool — Whether requests may change the router: set the system identity, run scripts and reboot. A write community is a powerful credential, so keep its name hard to guess and its addresses narrow. Default: no.
  • denied-oids multi { array-id, oid: string } — OIDs or subtrees that this community cannot read. A direct GET of a blacklisted OID returns no-such-object and a walk skips the blocked subtree, so a monitoring tool's poll does not fail. Several OIDs can be given as a comma-separated list. The setting is per community. Default: empty (everything the agent implements is readable).
  • authentication-protocol enum (MD5 | SHA1 | SHA256 | SHA384 | SHA512) { MD5:0, SHA1:1, SHA256:2, SHA384:3, SHA512:4 } — Authentication protocol for SNMPv3 with security=authorized or private; all clients of the community must use it. - MD5 (default) - SHA1 - SHA256 - SHA384 - SHA512
  • encryption-protocol enum (DES | AES | AES256) — Encryption protocol for SNMPv3 with security=private. - DES (default) - AES - AES-128, defined in RFC 3826. - AES256 - AES-256.
  • authentication-password string — Password for SNMPv3 authentication, at least 8 characters. Sensitive; see the list of menus with sensitive parameters.
  • encryption-password string — Password for SNMPv3 encryption, at least 8 characters. Sensitive; see the list of menus with sensitive parameters.

snmp/send-trap

Type: Command

The send-trap command sends one SNMP trap to the configured trap target immediately, which is useful for testing that traps reach the collector. The trap uses the trap-target, trap-community, and trap-version settings of the SNMP service (with trap-version=1 it is a classic v1 enterprise trap; otherwise it carries the OID and value under the MikroTik trap OID 1.3.6.1.4.1.14988.1.1.9.0.1). See the SNMP guide for the trap configuration.

Argument / Type / Description

  • oid string — OID of the object the trap reports.
  • type enum (integer | string | nullobj | obj-id | ip-address | counter32 | timeticks | unsigned) { integer:0x02, string:0x04, nullobj:0x05, obj-id:0x06, ip-address:0x40, counter32:0x41, timeticks:0x43, unsigned:0x47 } — SNMP type of the value. Accepted values: - integer - A signed integer. - string - An octet string. - nullobj - A NULL value. - obj-id - An object identifier. - ip-address - An IP address. - counter32 - A 32-bit counter. - timeticks - A time in hundredths of a second. - unsigned - An unsigned integer.
  • value string — Value to send, in the format the selected type expects.
