simple

Simple queues: rate limits for the upload and download of a target address, network or interface. See the Simple queue guide.

queue/simple

Type: Directory

Simple queues: rate limits for the upload and download of a target address, network or interface. See the Simple queue guide.

Flag / Name / Description

  • X disabled — The queue is disabled.
  • I invalid — The queue is not in use, for example outside its time range or when its queue type does not exist.
  • D dynamic — The queue was created by another RouterOS service, not by the user.

Argument / Type / Description

  • name string — Name of the queue.
  • target object { target: alt { target-interface: iface_enum , target-address: alt { ip-address: ipPrefix , ipv6-address: ip6Prefix } } } — Addresses, networks or interfaces whose traffic the queue limits. Upload is the traffic that the target sends, download is the traffic that it receives. A simple queue must match a packet either by source or by destination: if both ends of a connection are inside the target, all its packets count as download.
  • dst alt { ip-address: ipPrefix , ipv6-address: ip6Prefix , interface: iface_enum } — Destination address, network or interface. The queue takes only the traffic between the target and this destination.
  • parent enum (none) { none:0 } — Parent simple queue, or none. Child queues share the rate of their parent. Default: none.
  • packet-marks multi { array-id, packet-mark: enum } — Packet marks that the queue takes. Empty means that the queue does not check packet marks. Default: empty.
  • priority composite { upload-priority: num [1 .. 8] , download-priority: num [1 .. 8] } — Priority of a child queue for upload and download, from 1 (highest) to 8 (lowest). Default: 8/8.
  • queue composite { upload-queue: enum , download-queue: enum } — Queue type for upload and download. Default: default-small/default-small.
  • limit-at composite { upload-limit-at: num , download-limit-at: num } — Rate that the queue gets when the queues of the same parent together ask for more than the parent allows. See HTB. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • max-limit composite { upload-max-limit: num , download-max-limit: num } — Highest rate that the queue allows. 0 means no limit. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-limit composite { upload-burst-limit: num , download-burst-limit: num } — Highest rate that the queue allows while burst is active. See Queue Burst. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-threshold composite { upload-threshold: num , download-threshold: num } — Average rate up to which burst is allowed. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-time composite { upload-burst-time: time , download-burst-time: time } — Time over which the average rate for burst is calculated. Default: 0s.
  • bucket-size composite { upload-bucket-size: num [ .. 10000] , download-bucket-size: num [ .. 10000] } — Size of the HTB token bucket as a multiple of max-limit. See HTB. Default: 0.1.
  • total-priority num — Priority for the limit of upload and download together. Default: not set.
  • total-queue enum — Queue type for the limit of upload and download together. Default: not set.
  • total-limit-at num — limit-at for upload and download together. Default: not set.
  • total-max-limit num — Highest rate for upload and download together. Default: not set.
  • total-burst-limit num — burst-limit for upload and download together. Default: not set.
  • total-burst-threshold num — burst-threshold for upload and download together. Default: not set.
  • total-burst-time time — burst-time for upload and download together. Default: not set.
  • total-bucket-size num — bucket-size for upload and download together. Default: not set.
  • time super { ! , start: time , [end] -time , [day] ,ubit (sun, mon, tue, wed, thu, fri, sat) } — Time range and days in which the queue is active. Outside this time the queue has the I flag and limits no traffic. Default: not set, always active.

Read-only Argument / Type / Description

  • bytes composite { upload: num , download: num } — Number of bytes that passed the queue.
  • total-bytes num — Number of bytes counted by the limit of upload and download together.
  • packets composite { upload: num , download: num } — Number of packets that passed the queue.
  • total-packets num — Number of packets counted by the limit of upload and download together.
  • dropped composite { upload: num , download: num } — Number of packets that the queue dropped.
  • total-dropped num — Number of packets dropped by the limit of upload and download together.
  • rate composite { upload: num , download: num } — Average rate of the traffic that passes the queue, in bits per second, for upload and download.
  • total-rate num — Average rate counted by the limit of upload and download together, in bits per second.
  • packet-rate composite { upload: num , download: num } — Average rate of the traffic that passes the queue, in packets per second.
  • total-packet-rate num — Average rate counted by the limit of upload and download together, in packets per second.
  • queued-packets composite { upload: num , download: num } — Number of packets that wait in the queue.
  • total-queued-packets num — Number of packets that wait in the queue for upload and download together.
  • queued-bytes composite { upload: num , download: num } — Number of bytes that wait in the queue.
  • total-queued-bytes num — Number of bytes that wait in the queue for upload and download together.
  • pcq-queues composite { upload: num , download: num } — Number of PCQ sub-streams, when the queue type is a PCQ type.
  • total-pcq-queues num — Number of PCQ sub-streams of the queue for upload and download together.

tree

Queue tree: rate limits for traffic in one direction, selected by packet mark, on an interface or globally. See the Queue tree guide.

queue/tree

Type: Directory

Queue tree: rate limits for traffic in one direction, selected by packet mark, on an interface or globally. See the Queue tree guide.

Flag / Name / Description

  • X disabled — The queue is disabled.
  • I invalid — The queue is invalid and not in use.

Argument / Type / Description

  • name string — Name of the queue.
  • parent enum (global) { global:0xfffff4 } — Where the queue is attached: an interface, global, or another queue tree entry.
  • packet-mark multi { array-id, packet-mark: enum } — Packet mark that the queue takes. no-mark takes the packets that have no packet mark. Leave it empty on a queue that has child queues. Default: empty.
  • limit-at num — Rate that the queue gets when the queues of the same parent together ask for more than the parent allows. See HTB. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • queue enum — Queue type. Default: default-small.
  • priority num — Priority of a child queue, from 1 (highest) to 8 (lowest). Default: 8.
  • max-limit num — Highest rate that the queue allows. 0 means no limit. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-limit num — Highest rate that the queue allows while burst is active. See Queue Burst. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-threshold num — Average rate up to which burst is allowed. Default: 0. The value is in bits per second; the suffixes k and M are accepted.
  • burst-time time — Time over which the average rate for burst is calculated. Default: 0s.
  • bucket-size num — Size of the HTB token bucket as a multiple of max-limit. See HTB. Default: 0.1.

Read-only Argument / Type / Description

  • bytes num — Number of bytes that passed the queue.
  • packets num — Number of packets that passed the queue.
  • dropped num — Number of packets that the queue dropped.
  • rate num — Average rate of the traffic that passes the queue, in bits per second.
  • packet-rate num — Average rate of the traffic that passes the queue, in packets per second.
  • queued-packets num — Number of packets that wait in the queue.
  • queued-bytes num — Number of bytes that wait in the queue.
  • pcq-queues num — Number of PCQ sub-streams, when the queue type is a PCQ type.

RouterOS command reference for /queue/tree/reset-counters.

queue/tree/reset-counters

type

Queue types: named sets of settings for a queuing algorithm. Simple queues, queue trees and interface queues use them. See the Queue types guide.

queue/type

Type: Directory

Queue types: named sets of settings for a queuing algorithm. Simple queues, queue trees and interface queues use them. See the Queue types guide.

Flag / Name / Description

  • ***** default — Default queue type. Its settings can be changed, but it cannot be removed.

Argument / Type / Description

  • name string — Name of the queue type.
  • kind enum (bfifo | pfifo | red | sfq | pcq | mq-pfifo | none | codel | fq-codel | cake) { bfifo:1, pfifo:2, red:3, sfq:4, pcq:5, mq-pfifo:6, none:7, codel:8, fq-codel:9, cake:10 } — Queuing algorithm of the type. none means no software queue. See Queue types for a description of each kind.
  • bfifo-limit num — Queue size in bytes. Default: 15000.
  • pfifo-limit num — Queue size in packets. Default: 50.
  • red-limit num — Hard limit of the queue, in packets. Default: 60.
  • red-min-threshold num — Average queue size, in packets, at which RED starts to drop packets at random. Default: 10.
  • red-max-threshold num — Average queue size, in packets, at which RED drops every new packet. Default: 50.
  • red-burst num — Number of packets that RED accepts in a burst before the average queue size follows. Default: 20.
  • red-avg-packet num — Average packet size in bytes that RED uses to calculate the average queue size. Default: 1000.
  • sfq-perturb num — Time in seconds after which SFQ changes how it sorts packets into flows. Default: 5.
  • sfq-allot num — Number of bytes that a flow sends in one turn. Default: 1514.
  • pcq-rate num — Rate limit of each sub-stream, in bits per second. 0 means no limit for a sub-stream: every active sub-stream sends the same number of packets. Default: 0.
  • pcq-limit num — Queue size of one sub-stream, in KiB. Default: 50KiB.
  • pcq-classifier ubit (src-address, dst-address, src-port, dst-port) — What one sub-stream is. Select one or several values. Default: empty, all traffic is one sub-stream.
  • pcq-total-limit num — Queue size of all sub-streams together, in KiB. Default: 2000KiB.
  • pcq-burst-rate num — Rate that a sub-stream can reach while burst is allowed. See Queue Burst. Default: 0.
  • pcq-burst-threshold num — Average rate of a sub-stream up to which burst is allowed. Default: 0.
  • pcq-burst-time time — Time over which the average rate of a sub-stream is calculated. Default: 10s.
  • pcq-src-address-mask num — Prefix length of the IPv4 network that is one sub-stream when the classifier has src-address. Default: 32.
  • pcq-dst-address-mask num — Prefix length of the IPv4 network that is one sub-stream when the classifier has dst-address. Default: 32.
  • pcq-src-address6-mask num — Prefix length of the IPv6 network that is one sub-stream when the classifier has src-address. Default: 128.
  • pcq-dst-address6-mask num — Prefix length of the IPv6 network that is one sub-stream when the classifier has dst-address. Default: 128.
  • mq-pfifo-limit num — Size of each queue in packets. Default: 50.
  • codel-limit num — Hard limit of the queue, in packets. Default: 1000.
  • codel-interval time — Time over which CoDel checks the waiting time of packets. Set it to about the round-trip time of the connections. Default: 100ms.
  • codel-target time — Waiting time of packets that the queue accepts. Default: 5ms.
  • codel-ecn bool — Whether CoDel marks packets of ECN-capable connections instead of dropping them. Default: no.
  • codel-ce-threshold time — Waiting time from which CoDel marks packets of ECN-capable connections. Default: not set.
  • fq-codel-limit num — Hard limit of all flow queues together, in packets. Default: 10240.
  • fq-codel-interval time — Time over which CoDel checks the waiting time of packets. Set it to about the round-trip time of the connections. Default: 100ms.
  • fq-codel-target time — Waiting time of packets that the queue accepts. Default: 5ms.
  • fq-codel-ecn bool — Whether FQ-CoDel marks packets of ECN-capable connections instead of dropping them. Default: yes.
  • fq-codel-ce-threshold time — Waiting time from which FQ-CoDel marks packets of ECN-capable connections. Default: not set.
  • fq-codel-flows num — Number of flow queues into which FQ-CoDel sorts packets. Default: 1024.
  • fq-codel-memlimit num — Memory limit for the packets in all flow queues together. Default: 32.0MiB.
  • fq-codel-quantum num — Number of bytes that a flow sends in one turn. Default: 1514.
  • cake-bandwidth num — Rate of the shaper that is built into CAKE. 0 means no shaping by CAKE: use it when HTB sets the rate. Default: 0. See CAKE.
  • cake-autorate-ingress bool — Whether CAKE estimates the link capacity from the arriving packets and adjusts its shaper. Default: not set.
  • cake-overhead num — Bytes that CAKE adds to the size of each packet for the overhead of the link, from -64 to 256. Default: 0.
  • cake-mpu num — Smallest packet size on the link, in bytes, from 0 to 256. Smaller packets are counted with this size. Default: not set.
  • cake-atm enum (none | atm | ptm) { none:0, atm:1, ptm:2 } — Framing compensation: atm for ATM cells, ptm for PTM encoding, none. Default: not set.
  • cake-overhead-scheme multi { cake-overhead-scheme: enum (raw | conservative | ipoa-vcmux | ipoa-llcsnap | bridged-vcmux | bridged-llcsnap | pppoa-vcmux | pppoa-llc | pppoe-vcmux | pppoe-llcsnap | pppoe-ptm | bridged-ptm | via-ethernet | ethernet | ether-vlan | docsis) { raw:1, conservative:2, ipoa-vcmux:3, ipoa-llcsnap:4, bridged-vcmux:5, bridged-llcsnap:6, pppoa-vcmux:7, pppoa-llc:8, pppoe-vcmux:9, pppoe-llcsnap:10, pppoe-ptm:11, bridged-ptm:12, via-ethernet:13, ethernet:14, ether-vlan:15, docsis:16 } } — Preset for cake-overhead, cake-mpu and cake-atm that matches a link technology. Default: empty. See CAKE.
  • cake-rtt time — Round-trip time that CAKE uses to tune its queue management. Default: 100ms.
  • cake-rtt-scheme enum (none | datacentre | lan | metro | regional | internet | oceanic | satellite | interplanetary) { none:0, datacentre:1, lan:2, metro:3, regional:4, internet:5, oceanic:6, satellite:7, interplanetary:8 } — Preset for cake-rtt. Default: not set. See CAKE.
  • cake-diffserv enum (diffserv3 | diffserv4 | diffserv8 | besteffort | precedence) { diffserv3:0, diffserv4:1, diffserv8:2, besteffort:3, precedence:4 } — How CAKE sorts packets into priority classes by their DSCP value. besteffort uses one class. Default: diffserv3. See CAKE.
  • cake-flowmode enum (flowblind | srchost | dsthost | hosts | flows | dual-srchost | dual-dsthost | triple-isolate) { flowblind:0, srchost:1, dsthost:2, hosts:3, flows:4, dual-srchost:5, dual-dsthost:6, triple-isolate:7 } — How CAKE separates traffic into queues: by flow, by source or destination host, or by both. Default: triple-isolate. See CAKE.
  • cake-nat bool — Whether CAKE looks up the addresses before NAT, so that it separates the hosts behind a router that translates addresses. Default: no.
  • cake-wash bool — Whether CAKE clears the DSCP value of the packets after it has used it. Default: no.
  • cake-ack-filter enum (none | filter | aggressive) { none:0, filter:1, aggressive:2 } — Whether CAKE removes redundant TCP acknowledgments: none, filter or aggressive. Default: none.
  • cake-memlimit num — Memory limit for the packets that CAKE holds in its queues. Default: not set.
