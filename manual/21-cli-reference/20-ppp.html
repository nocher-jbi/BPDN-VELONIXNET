ppp/aaa

Type: Settings Directory

RADIUS authentication and accounting for PPP users. See PPP AAA and RADIUS for the full guides.

Argument / Type / Description

  • use-radius bool — Whether the router asks a RADIUS server about users that have no secret on the router. A /radius entry with service=ppp must exist. Default: no.
  • accounting bool — Whether the router sends RADIUS accounting requests for PPP sessions. Default: yes.
  • use-circuit-id-in-nas-port-id bool
  • interim-update time — Interval of the Interim-Update accounting requests. Default: 0s, none are sent unless the server sets an interval for the session.
  • enable-ipv6-accounting bool — Whether IPv6 traffic is reported separately in the accounting requests. By default the counters have layer 2, IPv4 and IPv6 traffic together. The user needs a prefix from the PPP service and a rate limit, because the counters of the dynamic queue are used. It does not work for prefixes that the dynamic DHCPv6 server delegates (dhcpv6-pd-pool), because DHCP assigns them, not PPP. Default: no.

active

Connected PPP users. Remove an entry to disconnect the user. See PPP AAA for the full guide.

ppp/active

Type: Directory

Connected PPP users. Remove an entry to disconnect the user. See PPP AAA for the full guide.

Flag / Name / Description

  • R radius — A RADIUS server authenticated the user.

Read-only Argument / Type / Description

  • name string — User name given at the login.
  • service enum (any | async | pptp | pppoe | l2tp | ovpn | sstp) { any:0, async:1, pptp:2, pppoe:3, l2tp:5, ovpn:6, sstp:7 } — PPP server the user is connected to.
  • caller-id string — Address the user connected from: an IP address for L2TP and PPTP, a MAC address for PPPoE.
  • address ipAddr — Address the user got from the router.
  • uptime time — Time since the user connected.
  • encoding string — Encryption and compression of the link, for example MPPE128 stateless.
  • session-id num — ID of the session.
  • limit-bytes-in num — Number of bytes the user can upload in this session. 0 means no limit.
  • limit-bytes-out num — Number of bytes the user can download in this session. 0 means no limit.

ppp/profile

Type: Directory

PPP profiles: settings shared by the users in /ppp/secret and by the PPP servers and clients that use the profile. See PPP AAA for the full guide.

Flag / Name / Description

  • ***** default — Built-in profile (default or default-encryption). It cannot be removed.

Argument / Type / Description

  • name string — Name of the profile.
  • local-address alt { pool: enum , address: ipAddr } — Address of the router inside the tunnel, or the name of an IP pool that gives it.
  • remote-address alt { pool: enum , address: ipAddr } — Address of the user inside the tunnel, or the name of an IP pool that gives it. An address in the secret takes precedence.
  • remote-ipv6-prefix-pool enum () — IPv6 pool that gives each user a prefix. The router advertises the prefix on the interface of the user and adds a route to it. Default: none.
  • remote-ipv6-prefix-reuse bool — With a remote-ipv6-prefix-pool that holds a single /64 prefix, the prefix can be given to one PPP client only. With yes, the same prefix is given to all clients of the profile. Default: no.
  • dhcpv6-pd-pool enum () — IPv6 pool for prefix delegation. When a user connects, the router adds a dynamic DHCPv6 server on the interface of the user that delegates a prefix from this pool.
  • dhcpv6-use-radius bool — Value of use-radius of the dynamic DHCPv6 server. Default: no.
  • dhcpv6-lease-time time — Lease time of the dynamic DHCPv6 server. Default: 1d.
  • bridge iface_enum — Bridge to which the interface of the user is added as a port. Both ends of the tunnel must bridge the PPP interface; see Bridging and switching.
  • bridge-port-priority num — Priority of the dynamic bridge port, used by STP and RSTP to select the root port, and by MSTP to select the root port between regions. Has no effect when the bridge has protocol-mode=none. Range: 0..240.
  • bridge-path-cost num — Path cost of the dynamic bridge port, used by STP and RSTP to select the best path, and by MSTP to select the best path between regions. Has no effect when the bridge has protocol-mode=none. Range: 1..200000000.
  • bridge-horizon num — Split-horizon value of the dynamic bridge port. Ports with the same value do not forward frames to each other, which prevents bridging loops and isolates traffic. Range: 0..429496729.
  • bridge-learning enum (default | no | yes) { default:0xffffffff, no:0, yes:1 } — MAC learning on the dynamic bridge port. - default (default) - Takes the value from the default profile of the PPP server; yes if this is that profile. - no - MAC learning is off. - yes - MAC learning is on.
  • bridge-port-vid num — PVID of the dynamic bridge port. Has an effect only with vlan-filtering=yes on the bridge. Range: 1..4094. Default: 1.
  • bridge-port-trusted bool — Whether the dynamic bridge port is trusted for DHCP snooping. Default: no.
  • session-timeout time — Maximum time a session can stay connected. When it ends, the router disconnects the user. Default: not set, no limit.
  • idle-timeout time — Time without traffic after which the router disconnects the user. Default: not set.
  • use-ipv6 enum (default | no | yes | required) { default:0xffffffff, no:0, yes:1, required:2 } — Whether IPv6 is negotiated on the link. - yes (default) - IPv6 is allowed. - no - IPv6 is off. - required - The link is refused without IPv6. - default - Takes the value from the default profile of the PPP server; no if this is that profile.
  • use-mpls enum (default | no | yes | required) { default:0xffffffff, no:0, yes:1, required:2 } — Whether MPLS is allowed over the link. - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - MPLS is off. - yes - MPLS is allowed. - required - The link is refused without MPLS.
  • use-compression enum (default | no | yes) { default:0xffffffff, no:0, yes:1 } — Whether data compression is used. Has no effect on OpenVPN tunnels. - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - Off. - yes - On.
  • use-encryption enum (default | no | yes | required) { default:0xffffffff, no:0, yes:1, required:2 } — Whether data encryption (MPPE) is used. Has no effect on OpenVPN and SSTP tunnels. - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - No encryption. - yes - Encryption is used when the other side supports it. - required - The link is refused without encryption.
  • only-one enum (default | no | yes) { default:0xffffffff, no:0, yes:1 } — Whether a user can have only one session at a time, on all PPP servers together. Also applies to users that a RADIUS server authenticates. - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - A user can connect several times with the same name. - yes - A second connection of the user is refused while the first one is active.
  • change-tcp-mss enum (default | no | yes) { default:0xffffffff, no:0, yes:1 } — Whether the router adjusts the MSS of TCP connections to the MTU of the link (IPv4 only). - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - Off. - yes - On.
  • use-upnp enum (default | no | yes) { default:0xffffffff, no:0, yes:1 } — Whether UPnP is allowed on the interface of the user. - default (default) - Takes the value from the default profile of the PPP server; no if this is that profile. - no - Off. - yes - On.
  • rate-limit string — Rate limit of each user of the profile, applied as a dynamic simple queue when the user connects: rx-rate[/tx-rate] [rx-burst-rate[/tx-burst-rate] [rx-burst-threshold[/tx-burst-threshold] [rx-burst-time[/tx-burst-time] [priority [rx-rate-min[/tx-rate-min]]]]]]. The rates are from the point of view of the router: rx is the upload of the user and tx the download. Rates are in bits per second, with an optional k or M. See RADIUS for the details of the format.
  • insert-queue-before enum (bottom | first) { bottom:0xffffffff, first:0 } — Place of the dynamic queue in the simple queue list: bottom, first, or the name of a queue to put it before.
  • parent-queue enum (none) { none:0 } — Simple queue that becomes the parent of the dynamic queues of the users. Default: none.
  • queue-type composite { upload-queue: enum , download-queue: enum } — Queue types of the dynamic queue, as upload/download: the first is for the traffic received from the user, the second for the traffic sent to the user. Both must be given.
  • incoming-filter enum — Firewall filter chain for the packets that come from the user. The router adds a dynamic rule to the chain ppp that jumps to this chain. The chain ppp is reached only when a rule of another chain jumps to it.
  • outgoing-filter enum — Firewall filter chain for the packets that go to the user. The router adds a dynamic rule to the chain ppp that jumps to this chain. The chain ppp is reached only when a rule of another chain jumps to it.
  • address-list multi { address-list: enum } — Firewall address list to which the address of the user is added while the user is connected. On a PPP client, the address the client received.
  • interface-list enum — Interface list to which the interface of the user is added while the user is connected.
  • dns-server multi { address: ipAddr } — One or two IP addresses of DNS servers that the router gives to the PPP clients in the IPCP negotiation (RFC 1877). A client gets them only if it asks for them; a RouterOS client does with use-peer-dns=yes.
  • wins-server multi { address: ipAddr } — IP address of the WINS server that is offered to Windows clients.
  • on-up alt { script: string } — Script that runs when a user connects. It can read the variables user, local-address, remote-address, caller-id, called-id and interface. interface has the ID of the interface, not its name.
  • on-down alt { script: string } — Script that runs when a user disconnects. It has the same variables as on-up.

secret

PPP users of the router. All PPP servers use this list. See PPP AAA for the full guide.

ppp/secret

Type: Directory

PPP users of the router. All PPP servers use this list. See PPP AAA for the full guide.

Flag / Name / Description

  • X disabled — The secret is disabled and cannot be used to log in.

Argument / Type / Description

  • name string — Name of the user.
  • service enum (any | async | pptp | pppoe | l2tp | ovpn | sstp) { any:0, async:1, pptp:2, pppoe:3, l2tp:5, ovpn:6, sstp:7 } — PPP server that the user can log in to: async, pptp, pppoe, l2tp, ovpn or sstp. A login to another server is refused. Default: any.
  • caller-id string — Address the user must connect from. For L2TP and PPTP it is the IP address of the client, for PPPoE the MAC address in capital letters. A login from another address is refused. Default: empty, any address.
  • password string — Password of the user. This is a sensitive parameter.
  • profile enum — Profile of the user. Default: default.
  • local-address super { address: ipAddr } — Address of the router inside the tunnel for this user. Takes precedence over the profile.
  • remote-address super { remote-address: ipAddr } — Address of the user inside the tunnel. Takes precedence over the address or the pool of the profile.
  • routes string — Routes that the router adds while the user is connected, as dst-address gateway metric, for example 192.168.50.0/24 10.0.0.5 1. Other forms are not accepted. Several routes are separated with commas. Ignored for OpenVPN.
  • ipv6-routes string — IPv6 networks that the router routes to the interface of the user while the user is connected, for example 2001:db8:99::/64.
  • remote-ipv6-prefix super { remote-prefix: ip6Prefix } — IPv6 prefix of the user. The router adds it to the ND prefix list of the interface of the user, so the client can configure an address with stateless address autoconfiguration.
  • limit-bytes-in num — Number of bytes the user can upload in one session. When it is reached, the router disconnects the user. Default: 0, no limit.
  • limit-bytes-out num — Number of bytes the user can download in one session. When it is reached, the router disconnects the user. Default: 0, no limit.

Read-only Argument / Type / Description

  • last-logged-out date — Time of the last disconnect of the user.
  • last-caller-id string — Address the user connected from the last time.
  • last-disconnect-reason enum (peer-request | hung-up | idle-timeout | session-timeout | reset | reboot | port-error | nas-error | nas-request) { peer-request:1, hung-up:2, idle-timeout:4, session-timeout:5, reset:6, reboot:7, port-error:8, nas-error:9, nas-request:10 } — Reason of the last disconnect, for example peer-request (the client disconnected), session-timeout, or nas-request (the session was removed on the router).
