xfrm

interface/xfrm

Type: Directory

An XFRM interface provides a route-based IPsec endpoint. Bind an IPsec policy group to the interface, then route traffic for the remote network through the interface. The policies in the bound group encrypt traffic that enters the interface, and decrypted traffic is delivered through the same interface.

See Route-based IPsec with XFRM interfaces for a configuration example.

Flag / Name / Description

  • X disabled — Whether the interface is disabled.
  • R running — Whether the interface is running. The flag appears when an IPsec SA that uses the interface is established.

Argument / Type / Description

  • name string — Interface name.
  • mtu num — Layer 3 maximum transmission unit. Default: 1400.
